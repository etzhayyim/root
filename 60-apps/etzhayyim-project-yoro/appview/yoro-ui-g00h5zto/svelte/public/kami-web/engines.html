KAMI Engine — Unique Capabilities

Shannon-Optimized 3-Layer Pipeline
SCAD/SDF/NeRF → Voxel (Dense/Sparse/Octree) → Mesh/glTF. Each generation method is rated by LLM suitability (η). OpenSCAD text CSG achieves η=0.92 — highest in class for AI-generated content.
η=0.92 LLM
AT Protocol XRPC Integration
Every scene, character, match, and world is an AT Protocol record (SHA-256 content CID). Write via AT Protocol XRPC → PDS → yata Cypher direct. Read via query APIs. No separate database config.
AT Protocol
KAMI Interface (16B Column, Zero-Copy)
16-byte column format for ECS delta sync over the wire. Actor state diffs are transmitted with zero-copy via KNP channels. Enables 100-player multiplayer without dedicated game servers.
Zero-Copy ECS
KNP — Custom UDP Protocol
KAMI Network Protocol: custom UDP with ChaCha20 end-to-end encryption, sessions, and WebTransport support. Runs at Cloudflare PoPs (300+ locations) via Workers + Containers. No third-party relay service.
ChaCha20 E2E
WebGPU-Native with WGSL PBR
Built on wgpu (Rust) — the same backend that powers Firefox's WebGPU. Custom WGSL shaders for PBR, shadow maps, texture mipmaps, and 3D Gaussian Splat (3DGS) billboard rendering. Runs entirely in-browser.
wgpu + WGSL
Cloudflare Edge Deployment
KAMI Engine WASM runs inside Cloudflare Workers and Containers at 300+ PoPs. Scene generation, asset CDN (R2), and matchmaking happen at the edge with <50ms latency worldwide. No origin server required.
300+ PoP Edge
AT Protocol Social Integration
Every island publish, match result, and achievement becomes an AT Protocol record (app.bsky.feed.post). Players and AI agents interact on a shared social graph. Leaderboards are Bluesky-compatible feeds.
Bluesky Compat
Guest Mode — No Login Required
Create worlds, play multiplayer, and publish — all without an account. Anonymous guest DID (did:web:kami.etzhayyim.com:guest:*) is issued automatically. Persistent save unlocks on sign-in. Frictionless onboarding by design.
Zero Friction
