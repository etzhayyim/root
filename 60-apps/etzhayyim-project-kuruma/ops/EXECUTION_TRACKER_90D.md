# kuruma 90-Day Execution Tracker

Source plan: `BUSINESS_PLAN.md`
Objective (phase-0 to phase-1 execution): build the minimum growth engine for "Japan info -> Global traffic".

## North-star targets (Day 90)

- Indexed quality pages: 500+
- Monthly PV run-rate: 80,000+
- Tier-1 locales live: `ja`, `en`
- Tier-2 pilot locale live: at least one from `es`/`pt`/`de`/`fr`
- CWV mobile pass rate (money pages): 80%+

## Weekly Plan

### Week 1-2: Foundation

- [ ] Finalize 1,000-keyword map (JA source + EN mapped intent)
- [ ] Define page-type templates: `spec`, `compare`, `review`, `ownership`
- [ ] Set canonical/hreflang/sitemap baseline rules
- [ ] Add KPI dashboard spec (PV, indexation, net eCPM, viewability)

Exit criteria:
- [ ] 1,000 keywords approved
- [ ] technical SEO checklist complete

### Week 3-4: Money Pages v1

- [ ] Publish top 100 money pages (JA first)
- [ ] Add EN pages for top 30 money pages
- [ ] Add internal links: compare <-> review <-> spec
- [ ] Deploy ad stack test (header + in-article + sticky)

Exit criteria:
- [ ] 100 JA pages live
- [ ] 30 EN pages live
- [ ] ad slots rendering on all templates

### Week 5-6: Indexation and Quality

- [ ] Run indexation audit and fix noindex/canonical issues
- [ ] Improve CWV bottlenecks on high-traffic templates
- [ ] Refresh underperforming pages (title/H1/meta/intro intent)
- [ ] Add 50 compare pages focused on high CPC terms

Exit criteria:
- [ ] mobile CWV pass >= 70%
- [ ] indexed pages >= 200

### Week 7-8: Global Pilot

- [ ] Launch one Tier-2 locale pilot (recommended: `es`)
- [ ] Localize top 30 pages with market notes (not literal translation)
- [ ] Add country landing pages (import/legal/ownership caveats)
- [ ] Expand maker catalog coverage and cross-links

Exit criteria:
- [ ] locale pilot pages >= 30
- [ ] non-JA traffic share >= 15%

### Week 9-10: Yield Optimization

- [ ] Measure template-level viewability and RPM
- [ ] Tune ad density per page type (guardrail first)
- [ ] Add high-intent comparison modules above fold
- [ ] Improve session depth with related-content widgets

Exit criteria:
- [ ] blended net eCPM >= 900 JPY
- [ ] viewability >= 60%

### Week 11-12: Scale Loop

- [ ] Expand to 500+ total quality pages
- [ ] Build weekly refresh pipeline for top pages
- [ ] Publish backlinkable data posts (Japan-market insights)
- [ ] Lock operating cadence and ownership

Exit criteria:
- [ ] 500+ quality pages live
- [ ] 80k PV/month run-rate

## KPI Sheet (update weekly)

- Acquisition: impressions, clicks, CTR, avg position by cluster
- Content: published count, refreshed count, indexation delay
- Monetization: PV, viewability, fill rate, net eCPM, RPM
- Quality: CWV pass, engagement time, bounce, complaint rate
