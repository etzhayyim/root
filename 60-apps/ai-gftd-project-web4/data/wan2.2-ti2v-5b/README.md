# Wan2.2 TI2V Data

This directory is reserved for large `Wan-AI/Wan2.2-TI2V-5B` artifacts used by the distributed MoE TI2V pipeline.

- Keep generated weights, shards, and caches under this path.
- Do not commit generated binaries to Git.
- Publish runtime artifacts to object storage or IPFS, then reference via manifests.
