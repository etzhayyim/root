# フロントエンドBDDテストのトラブルシューティング

## 現在の状況

フロントエンドBDDテストを実行すると、タイムアウトエラーが発生しています。

## 問題の原因

1. **タイムアウト設定**: Cucumberのデフォルトタイムアウトが5秒に設定されている可能性があります
2. **ページの読み込み**: Next.jsのページが正しく読み込まれていない可能性があります
3. **認証**: Clerk認証が必要なページにアクセスする際に、認証状態が正しく設定されていない可能性があります

## 解決方法

### 1. サーバーの起動確認

フロントエンドBDDテストを実行する前に、以下のサーバーが起動していることを確認してください：

```bash
# Next.js開発サーバー
pnpm dev

# GraphQLサーバー（別のターミナルで）
cd performers/services/graphql && cargo run --bin graphql
```

### 2. 認証状態の確認

Clerk認証が必要なページにアクセスするには、認証状態が保存されている必要があります：

```bash
# 認証状態ファイルの確認
ls -la playwright/.clerk/user.json
```

認証状態ファイルが存在しない場合は、PlaywrightのE2Eテストを実行して認証状態を保存してください：

```bash
pnpm test:e2e --grep "authentication"
```

### 3. タイムアウトの延長

`package.json`の`test:bdd:frontend:coverage`スクリプトに`--timeout 60000`オプションを追加しました。

### 4. デバッグ方法

フロントエンドBDDテストをデバッグするには、以下の方法があります：

1. **ヘッドレスモードを無効化**: `features/support/world.ts`の`initBrowser`メソッドで`headless: false`に設定
2. **スクリーンショットを取得**: エラー発生時にスクリーンショットを保存
3. **コンソールログを確認**: ページのコンソールログを確認

## 次のステップ

1. Next.js開発サーバーとGraphQLサーバーが起動していることを確認
2. Clerk認証状態が保存されていることを確認
3. フロントエンドBDDテストを再実行

## 注意事項

フロントエンドBDDテストは、実際のブラウザで実行されるため、以下の点に注意してください：

- テスト実行中は、ブラウザウィンドウを操作しないでください
- テスト実行中は、Next.js開発サーバーとGraphQLサーバーを停止しないでください
- テスト実行中は、他のプロセスがポート3000や8080を使用しないでください
