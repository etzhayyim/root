見立て (mitate)

慢性的な鼻詰まりの 5 条件 triage advisory — religious-corp etzhayyim 自前の self-care substrate です。

重要 (G3 disclaimer): このツールは医師の判断を代替するものではありません。 advisory output は (i) どの条件の可能性が高いか、(ii) いつ耳鼻科を受診すべきか、を補助するもので、 確定診断・処方・手術判断は必ず資格を持つ医師の対面診察を経てください。Emergency 徴候 (急性 anaphylaxis / 視力低下 / 意識障害 / 突然の重度頭痛 / 髄膜炎徴候 等) が認められた場合、 即時 119 救急要請または最寄り ER 受診してください。

このツールが扱う 5 条件

  1. アレルギー性鼻炎 (通年性 / IgE-mediated)
  2. 血管運動性鼻炎 (非アレルギー / 寒暖差・刺激 誘発)
  3. 慢性副鼻腔炎 (蓄膿症 / 12 週以上)
  4. 鼻中隔弯曲症 (片側永続的)
  5. 薬剤性鼻炎 (市販血管収縮点鼻 ≥7 日連用)

このツールが扱わないこと (constitutional non-goals)

  • Rx 処方の発行
  • 手術の執刀
  • 保険請求の自動化
  • 急性 anaphylaxis 自体への emergency response (ER routing のみ)
  • 5 歳未満の小児・妊娠期・免疫抑制下の自立判断 (必ず human review escalate)
  • 遺伝子検査結果の medical interpretation / 精神科診断 / 終末期 palliative

プライバシー

  • あなたの health data は XChaCha20-Poly1305 で暗号化され、あなた自身の passkey と Council 医療顧問 DID のみが復号できます (G2)
  • 保険会社・雇用主・広告主への data path は構造的に存在しません (G7)
  • 30 日ごとに rotating pseudonym DID が使われ、長期 longitudinal 追跡には passkey 再署名が必要です
  • 同意は revocable で、いつでも revoke 可能 (revocation で envelope 復号可能性が失われる)
