G3 advisory boundary:

  1. mitate は 診断 advisory ツール です。確定診断・処方・手術判断は資格を持つ医師の対面診察を経てください。
  2. 本ツールの triage 出力は (i) どの条件の可能性が高いかの top-3 posterior probability、 (ii) 受診すべき診療科 / 急ぐ程度の escalation 推奨、(iii) self-care 環境調整 advisory、 のいずれかを返します。Rx 処方・特定 brand 薬の宣伝・保険請求 自動化は提供しません。
  3. 5 歳未満の小児・妊娠期・授乳中・免疫抑制下・抗凝固薬服用中の方は、本ツールの advisory 単独で 自己判断せず、必ず human review (医師相談) 経由としてください (G6)。
  4. G5 emergency 徴候 (anaphylaxis / orbital cellulitis / 髄膜炎徴候 / 視力低下 / 意識障害 等) が 疑われる場合、本ツールは即座に ER routing instruction を表示します。advisory pipeline は中断されます。

Per ADR-2605260100 §G1 + §G3 + §G6.
