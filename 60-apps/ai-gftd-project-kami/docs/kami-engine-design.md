# KAMI Engine — Next-Gen Game Engine Design

## Design Principles

| Principle | Implementation |
|---|---|
| **Shannon η = 100%** | 1 format (KAMI Interface), 1 renderer (wgpu), 1 protocol (KNP), 0 redundancy |
| **Zero-copy pipeline** | Storage → ECS → GPU: no format conversion, pointer cast only |
| **All-platform** | Web (WebGPU), PC (Vulkan/Metal/DX12), iOS/Android (Metal/Vulkan), Console (PS5/Switch via wgpu HAL) |
| **LLM-first** | No editor. Code generated by LLM. API 規則性 + 型安全性 > 人間の ergonomics |
| **Actor Model** | Server-authoritative entities. Authority = Server / Client / Predicted |

## KAMI Interface (ipc.rs)

Arrow 本質 (columnar zero-copy) のゲーム特化版。

```
Arrow C Data Interface:  80B/column  (null bitmap, dictionary, release callback 含む)
KAMI Interface:          16B/column  (data ptr + len + dtype + stride のみ)

η improvement: 80B → 16B = 5× less metadata overhead
```

### Data flow (zero format conversion)

```
R2 (Arrow IPC) ──mmap──→ KamiFrame ──ptr cast──→ wgpu Buffer (GPU DMA)
                              │
                         compute_delta()
                              │
                         KamiDelta ──KNP──→ Network (5B header + columnar diff)
```

## KNP — KAMI Network Protocol

Custom UDP for all platforms. AAA 実績のある raw UDP approach (UE5, Source 2, Unity と同じ方針)。

```
Header (5B post-session):
  [flags:4bit | channel:4bit] [seq:16bit] [ack:16bit]

Channels:
  0: Unreliable     — position/rotation (60Hz, loss OK)
  1: ReliableOrdered — commands/chat (ACK + retransmit)
  2: ReliableUnordered — asset load/spawn
  3: Voice           — Opus + FEC

Encryption: ChaCha20-Poly1305 (ARM で AES-GCM より高速)
```

### Why not QUIC/WebTransport for native?

| | Custom UDP (KNP) | QUIC | WebTransport |
|---|---|---|---|
| PS5 | BSD socket ✓ | TLS stack 重い | 不可 |
| Switch | nn::socket ✓ | TLS stack 重い | 不可 |
| Header | 5B | 20-30B | 30-40B |
| Latency | ~3ms | ~5ms | ~10ms |
| AAA 実績 | 全タイトル | 0 | 0 |

WebTransport は browser fallback としてのみ使用。

## Network Architecture

```
Client (PS5/Switch/PC/iOS/Android) ── KNP (raw UDP) ──→ Edge PoP
Browser ── WebTransport datagram ──→ Edge PoP
                                        │
                                   CF Workers (DO)
                                   Island Actor state
                                   sleep to $0
```

Server 間通信 (将来: Aeron IPC 1-5µs) は client には公開しない。

## Renderer: wgpu 一本

ash (Vulkan raw) を除去し wgpu に統一。

```
wgpu → WebGPU   (browser)
wgpu → Vulkan   (PC Linux/Win, Android)
wgpu → Metal    (macOS, iOS)
wgpu → DX12     (PC Win fallback)
wgpu → GNM HAL  (PS5, future: custom wgpu-hal backend)
wgpu → NVN HAL  (Switch, future: custom wgpu-hal backend)
```

console 用 wgpu-hal backend は NDA 下で別 crate 開発。Engine 本体は変更不要。
