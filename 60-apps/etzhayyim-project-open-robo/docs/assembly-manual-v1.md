# Giemon Otete — 組立説明書 v1.0

**対象**: Giemon Otete 組み立てキット購入者
**所要時間**: 約4〜6時間（初回）
**必要工具**: ヘクサゴンレンチ M2.5/M3、プラスドライバー、ニッパー、電動ドリル（任意）
**難易度**: 中級（電子工作経験者向け）
**言語版**: 日本語 / English（裏面）
**改訂**: v1.0 / 2026-05-14

---

## 安全上のご注意

- バッテリーは逆接しないこと（BMS保護あり、ただし破損原因となる場合あり）
- サーボに通電した状態でトルクが発生します。指を挟まないよう注意
- アルミ切削面にはバリがある場合があります。組立時に手袋着用を推奨
- Raspberry Pi 5は静電気に敏感です。接触前にアース放電してください

## ステップ1: クローラーシャーシ組み立て（所要時間 約60分）

### 1-1 サイドプレートへのホイール軸取り付け

1. 左サイドプレート(01-002)を平らな作業台に置く
2. ホイールシャフト(SUS304 Φ8mm×80mm)を4か所の軸穴に差し込む
3. 内側からΦ8mmベアリング(608ZZ)を圧入（ゴムハンマーで軽打）
4. アイドラーホイールをシャフトに通し、M3止めネジで固定

```
サイドプレート断面（正面）
 ━━━━━━━━━━━━━━━━━━━━━━━
 ●         ●  ←前後アイドラーホイール
    ●   ●       ←中間ホイール（タミヤ70168）
 ━━━━━━━━━━━━━━━━━━━━━━━
       ↑
    駆動スプロケット（後部）
```

5. 右サイドプレート(01-003)も同様に組み立て

### 1-2 モーター取り付け

1. モーターマウントブラケット(01-011)をサイドプレート内面にM3×8mmボルト×4本で固定
2. マブチ RS-550PCをブラケットに差し込み、M3×12mmで固定
3. 駆動スプロケット(01-005)をモーターシャフト(D-cut)に差し込み
4. M3止めネジ × 2本で確実に固定（緩むとトラックが外れる原因）

### 1-3 ボトムプレート接続

1. ボトムプレート(01-001)にサイドプレートL/Rを内側から立て、M3×12mm ×8本で固定
2. 水平度を確認（平坦面に置いて4隅がガタつかないこと）

### 1-4 トラックベルト装着

1. タミヤ70168トラックベルトを前後ホイールに掛ける
2. テンションはアイドラーホイールの前後スライドで調整（3mm程度のたるみが適正）

---

## ステップ2: アームベース・J1旋回台組み立て（約30分）

### 2-1 トップマウントプレート取り付け

1. トップマウントプレート(01-004)をサイドプレート上部にM3×8mm × 8本で固定
2. 中央のJ1台座取付穴(PCD φ68mm, M3×6穴)の位置を確認

### 2-2 J1サーボ・旋回台ハウジング組み立て

1. KRS-6013IHVサーボをJ1ハウジング(02-001)下部に挿入
2. サーボ出力軸にアルミホーン（付属）を取り付け、M3×4mmで固定
3. ベアリング(6004ZZ)をハウジングに圧入
4. ハウジングをトップマウントプレートにM3×12mm × 6本で固定

---

## ステップ3: アームリンク組み立て（約60分）

### 3-1 J2 肩関節

```
  J1旋回台
      │
  ┌───┴───┐
  │  KRS  │  ← KRS-6013IHV
  │ 6013  │
  └───┬───┘
      │
  ┌───┴───────────────┐
  │   Shoulder_Link_A  │  長さ120mm
  │   (平行リンク)      │
  └───────────────────┘
```

1. KRS-6013IHVサーボをJ2ハウジングに固定
2. 肩リンクA(02-002)をサーボホーンにM3×8mm × 4本で接続
3. 平行リンクB(02-003)を同ピッチで取り付け（平行四辺形リンク機構）

### 3-2 J3 肘関節

1. KRS-4014ICSサーボをJ3ハウジング(02-004)に固定
2. 前腕リンク（ミスミアルミ押出し15×15 160mm）をJ3サーボホーンに接続
3. ミスミLブラケット(HBLSS3) × 2でリンク末端を補強

### 3-3 J4/J5/J6 手首3軸

1. J4(KRS-4014ICS), J5(KRS-2350IHV), J6(KRS-2350IHV)を順次ネスト
2. 各サーボのケーブルをフォームアーム内部を通してルーティング
   - ケーブル曲げ半径は最低30mm確保
   - タイラップでケーブルをリンクに固定（2か所以上）

### 3-4 グリッパー組み立て

1. グリッパーベース(02-009-001)にFutaba S3003を固定
2. 左右指(02-009-002/003)をサーボホーンリンク機構で連結
3. TPUインサートを指先に接着（スーパーXゴールド等）
4. 開閉動作確認: S3003 = 1500μs(中立)で開口40mm目標

## ステップ4: 電装系組み立て（約90分）

### 4-1 Raspberry Pi 5 + HAT 取り付け

```
         ┌─────────────────┐
         │  Otete HAT  │  ← ICS/RS485/モータードライバ
         ├─────────────────┤
         │  Raspberry Pi 5 │
         └─────────────────┘
                 ↓
         電装トレイ(01-013)にM3スペーサー 10mm経由で取付
```

1. M3×10mmスペーサーをRPi 5の取付穴(φ2.75mm)×4か所にセット
2. Otete HATをRPi 5の40pinGPIOコネクターにまっすぐ差し込む
3. 電装トレイ(01-013)にM3×10mm+M3×6mmボルトで固定

### 4-2 DC-DCコンバータ配線

```
バッテリー 14.8V ──┬── DC-DC 5V/5A ──→ RPi 5 USB-C（5V）
                   │                 → HAT 5V ロジック電源
                   ├── DC-DC 7.4V/3A → サーボ電源バス
                   └── 直結 12V      → クローラーモーター
```

1. TDKラムダ DC-DC(5V)を電装トレイにM3×8mmで固定
2. コーセル DC-DC(7.4V)を隣接配置
3. 入力側はXT30コネクターでバッテリーホルダーに接続
4. 出力側: 5V→RPi5 USB-C、7.4V→HATサーボバスコネクター

> **配線時の注意**: DC-DC出力電圧を事前に確認（テスター使用）。
> 5V出力が5.0±0.1V であることを確認してからRPiに接続。

### 4-3 サーボバスケーブル配線（ICS3.5）

```
Otete HAT ICS3.5 Port 1
    └── KRS-6013IHV (ID=1, J1)
        └── KRS-6013IHV (ID=2, J2)  ← デイジーチェーン
            └── KRS-4014ICS (ID=3, J3)
                └── KRS-4014ICS (ID=4, J4)
                    └── KRS-2350IHV (ID=5, J5)
                        └── KRS-2350IHV (ID=6, J6)

Otete HAT PWM Port 1
    └── Futaba S3003 (グリッパー, PWM 50Hz)
```

1. 各サーボのIDをPC接続で事前設定（近藤科学 RCTF またはICS USB アダプター使用）
2. J1→J2→J3...の順にICSケーブルをデイジーチェーン
3. J6末端はターミネーター不要（KRS 内部終端済み）

### 4-4 カメラ + センサー取り付け

1. カメラパン/チルトブラケット(03-003)をJ1ハウジング側面にM3×8mm × 2本
2. RPi Camera v3をブラケットに取り付け、CSIフレキをRPi 5 CAM0ポートへ
3. ToFセンサー(VL53L4CX) × 2個をクローラー前面に左右15°角度で配置
4. I2CケーブルをHATのI2Cコネクターへ接続（I2Cアドレス 0x29 / 0x30）

### 4-5 バッテリー配線

1. 18650電池×4本を4Sホルダーにプラス方向確認の上セット
2. BMSの保護基板をバッテリーベイ(01-014)内にゴムビスで固定
3. BMS出力→XT30コネクター→メインスイッチ→DC-DC入力
4. 残量LEDインジケーター（HAT内蔵）のプローブ線をBMSのBalanceタップへ

## ステップ5: ソフトウェアセットアップ（約30分）

### 5-1 OSインストール

```bash
# Raspberry Pi Imagerで microSDに書き込み
# OS: Ubuntu 22.04 LTS 64-bit (Raspberry Pi 5対応)
# カスタマイズ: WiFi設定、SSH有効、ホスト名=otete
```

### 5-2 ファームウェアインストール

```bash
# RPiにSSH接続後
git clone https://github.com/etzhayyim/otete-firmware
cd otete-firmware
./install.sh      # 依存パッケージ + ROS2 Humble + Python仮想環境
```

### 5-3 サーボID確認

```bash
python3 firmware/tools/servo_scan.py
# 出力例: Found servo IDs: [1, 2, 3, 4, 5, 6]
```

### 5-4 動作確認

```bash
python3 firmware/test/home_pose.py    # 全サーボをホームポジションへ
python3 firmware/test/drive_test.py   # クローラー前進0.5秒テスト
python3 firmware/test/camera_test.py  # カメラ映像確認
```

|---|---|---|

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| サーボが動かない | IDが設定されていない | `servo_scan.py`でID確認、未設定サーボに近藤科学ICS USB接続でID設定 |
| クローラーが一方向にしか動かない | モーター配線極性ミス | TB6612のAIN1/AIN2を入れ替え |
| RPi5が起動しない | 5V電圧不足 | DC-DC出力電圧を再確認。テスターで5.0±0.1V確認 |
| カメラが認識されない | CSIケーブル接続不良 | `/boot/firmware/config.txt` に `camera_auto_detect=1` 確認 |
| ICSバスエラー | ケーブル断線 | `servo_scan.py` で切り分け、ICSケーブル交換 |
| 走行時に異音 | トラックテンション不良 | アイドラーホイールを前後スライドで調整 |
