# Giemon Otete — BOM v1.0 部品調達仕様書

**製品名**: Giemon Otete
**コンセプト**: 6軸ロボットアーム + クローラーベース 組み立てキット
**参照競合**: HiWonder ArmPi Ultra
**設計方針**: Raspberry Pi 5（SBCのみ例外）+ 全構造・電装・筐体は日本調達・日本製造
**想定販売価格**: ¥89,800（税込）/ $599 USD
