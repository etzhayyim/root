# etzhayyim-project-public-sento

銭湯の立ち上げ・運営に特化した Public Fund プロジェクト。
`public-sento.etzhayyim.com` を公開窓口にし、資金調達・設備更新・運営費配分を一元管理する。

- 公開ドメイン: `public-sento.etzhayyim.com`
- API: XRPC-Web (`/xrpc`)
- 会計台帳: `credits.etzhayyim.com` を残高基盤として利用
- 運用対象:
  - 新規銭湯の開業準備 (物件・設備・法令対応)
  - 既存銭湯の改修/衛生強化/省エネ化
  - 地域イベント連動の公共浴場運営

## Scope

- Fund Campaign の起案と公開
- user からの credits 拠出 (Pledge)
- 申請受付/審査/承認/分配 (Disbursement)
- 運営KPIの可視化 (稼働率、衛生監査、地域利用率)
- 監査証跡の保持と公開ダッシュボード連携
