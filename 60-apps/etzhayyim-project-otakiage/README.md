# otakiage.etzhayyim.com

物の reuse → 供養 (お焚き上げ) を 1 つのライフサイクルで扱う Reuse & Ritual Platform。

- **対象 (Phase 1)**: 絵本 / 児童書、ぬいぐるみ / 人形 / おもちゃ、家具 / 大型家電
- **運営**: etzhayyim (宗教法人・任意団体・blockchain 登記)
- **差別化**: Mercari 型決済 escrow に対し、無償譲渡 + 季節の供養祭 + 永続証跡 (AT Record JSON / Phase 2 で ERC725 anchor)
