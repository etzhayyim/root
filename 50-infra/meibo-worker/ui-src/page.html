meibo 名簿 — verified legal-institution directory

弁護士会・裁判所・(日本の)司法書士会/行政書士会など、実在する機関の公式検索窓口への リンク集です。個人の弁護士・裁判官の記録は保持しません(機関レベルのリンクのみ)。 実際に検索する際は、下記リンク先の機関自身のサイトで行ってください。詳しくは /api/coverage も参照。

Apache 2.0 + etzhayyim Charter Compliance Rider. Source: com-etzhayyim-meibo. R0 seed — 10 jurisdictions; the rest honestly degrade to an empty result (G10). No cookies, no tracking script — access is logged only as anonymous aggregate counts (route/day), never per-visitor.
