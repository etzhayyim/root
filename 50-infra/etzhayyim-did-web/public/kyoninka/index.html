許認可 kyoninka

日本および世界でロボタクシーを公道で走らせるための法的・行政手続き(許認可)を、actor として設計・評価し可視化する。observe → recommend のみ: 許認可は付与せず、車両は起動しない。最終可否は人間の規制当局のサインオフ。

手続きフロー

1 run = 1 操作。封じ込めた reg-LLM の提案を、独立した PermitGovernor が法的不変条件で検閲し、公道走行は必ず規制当局へ。

受付デプロイ申請を受け、観測(法的状態の記録)か査定かに振り分け
→
助言(reg-LLM)封じ込めた reg-LLM が事実のみから準備度を提案(付与はしない)
→
検閲(PermitGovernor)独立ガバナーが法的不変条件で提案を検閲
→
判定commit / hold / 人間承認 へ振り分け(段階導入ゲート込み)
→
規制当局サインオフ公道走行は高リスク → 必ず人間の規制当局が承認(interrupt)
→
記録承認された準備度を不変台帳へ append(付与・起動はしない)
