# Zajęcie wynagrodzenia (賃金差押え・執行・ポーランド) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 komornik の行為への skarga
【件名】   Zajęcie wynagrodzenia (賃金差押え・執行・ポーランド) に対する komornik の行為への skarga (1週間)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【komornik の行為への skarga (1週間)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Kwota wolna (生計保護): 差押えは賃金の50%まで (alimenty は3/5) + **最低賃金 (minimalne wynagrodzenie) 相当は kwota wolna として必ず残る** (Kodeks pracy art. 87・87¹)
- 提出方法・控えの保管。不安があれば: nieodpłatna pomoc prawna (無料法律相談ポイント) / rzecznik konsumentów (消費者オンブズマン)
