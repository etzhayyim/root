# Answer to a family Application (家事・カナダ ON) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## まず公式様式を確認
- Answer (Form 10) を全当事者へ serve & file (認否 + 自分の claim があれば併せて) — **公式様式が存在します。自由書式より様式を優先**してください。
- 相手の Answer には Reply (Form 10A) を10日以内に — **公式様式が存在します。自由書式より様式を優先**してください。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Answer
【件名】   Answer to a family Application (家事・カナダ ON) に対する Answer (Form 10)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Answer (Form 10) を全当事者へ serve & file (認否 + 自分の claim があれば併せて)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Answer (Form 10) の serve & file: Application 送達から30日以内に Answer (Form 10) を全当事者へ serve & file (カナダ国外・米国外で送達されたなら60日); 期限内に応答しないと自分抜きで手続が進む。相手の Answer に対しては Reply (Form 10A) を10日以内に (Ontario; 家事手続は州管轄 — 通知記載と州規則を確認) (Ontario Family Law Rules (O Reg 114/99) r.10(1))
- 提出方法・控えの保管。不安があれば: provincial legal aid (例 Legal Aid Ontario) / law society referral service
