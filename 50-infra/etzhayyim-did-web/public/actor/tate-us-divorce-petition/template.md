# Petition for dissolution (家事・米国) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## まず公式様式を確認
- response form を期限内に提出 (default 回避が最優先) — **公式様式が存在します。自由書式より様式を優先**してください。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 response form を期限内に提出
【件名】   Petition for dissolution (家事・米国) に対する response form

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【response form を期限内に提出 (default 回避が最優先)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Response の提出: 送達から30日以内が多い (州 family code・通知記載を確認) — 無応答は default となり財産分与・監護が一方的に決まり得る (州 family code (例 Cal. Fam. Code §2020 系 / FL-120))
- 提出方法・控えの保管。不安があれば: state bar lawyer-referral service / Legal aid (lsc.gov)
