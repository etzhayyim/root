# Verificación de créditos (acreedor・concurso・アルゼンチン) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 pedido de verificación de créditos を síndico へ提出
【件名】   Verificación de créditos (acreedor・concurso・アルゼンチン) に対する pedido de verificación de créditos

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【pedido de verificación de créditos を síndico へ提出 (本人可; anticipo・seña・vale など前払金も crédito: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Pedido de verificación de créditos: sentencia de apertura が定める fecha (verificación tempestiva) までに pedido de verificación de créditos を síndico へ (monto・causa・privilegios を明示, art.32); 期日後は verificación tardía (art.56) — concurso 係属中は incidente、終了後は acción individual、いずれも presentación en concurso から2年以内 (Ley 24.522 art.32 (tempestiva) / art.56 (tardía))
- 提出方法・控えの保管。不安があれば: patrocinio jurídico gratuito (大学・公的) / Defensa del Consumidor 0800-666-1518
