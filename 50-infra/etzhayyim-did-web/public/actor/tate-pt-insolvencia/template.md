# Reclamação de créditos (債権者側・倒産・ポルトガル) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 reclamação de créditos を administrador de insolvência へ提出
【件名】   Reclamação de créditos (債権者側・倒産・ポルトガル) に対する reclamação de créditos

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【reclamação de créditos を administrador de insolvência へ提出 (本人可; adiantamento・caução・vale など前払金も crédito: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Reclamação de créditos: 破産判決 (sentença declaratória de insolvência, 公告) が定める期限内 — 通常は公告から30日以内 — に reclamação de créditos (requerimento + 疎明資料: 発生原因・期日・元本利息・性質を記載) を administrador de insolvência へ; 期限徒過は insolvência の確定から6か月内に verificação ulterior (別訴) を要する (CIRE art. 36.º / art. 128.º (徒過時 art. 146.º))
- 提出方法・控えの保管。不安があれば: apoio judiciário (Segurança Social 経由の法律扶助) / Ordem dos Advogados
