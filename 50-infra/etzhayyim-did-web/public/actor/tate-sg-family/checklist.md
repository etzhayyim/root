# Memorandum of Appearance + Defence (家事・シンガポール) — 自己対応チェックリスト

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

本物の書類の経路: originating claim / SCT notice は court service (post 含む) — SMS/WhatsApp の『court』通知は偽
SMS/メールのみの『裁判所』通知は接触せず: tasuke 助 (サイバー犯罪被害支援) / ScamShield / 1799 anti-scam helpline / Singapore Police Force

## 期限 (起算点=送達日を自分で確認)
- **Memorandum of Appearance + Defence**: divorce papers 送達後8日以内 (シンガポール国外で送達なら21日) に Memorandum of Appearance を file; Defence (または Defence and Counterclaim) は MOA 提出から14日以内; MOA 未提出は contested 扱い・default judgment になりうる (Family Justice Rules 2014 + Women's Charter — 要改正確認)

## 選択肢 (member 本人が決めて提出する — 代理はしない)
🛡 Memorandum of Appearance を期限内に file (応訴の意思表示)
- Defence (必要なら Counterclaim) を MOA から14日以内に file

- 子が21歳未満で counterclaim 提出時は Co-Parenting Programme (CPP) 受講
