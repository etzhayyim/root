# Forderungsanmeldung (債権者側・倒産・オーストリア) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Forderungsanmeldung を Landesgericht へ提出
【件名】   Forderungsanmeldung (債権者側・倒産・オーストリア) に対する Forderungsanmeldung

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Forderungsanmeldung を Landesgericht へ提出 (本人可; Anzahlung・Kaution・Gutschein など前払金も Forderung: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Forderungsanmeldung: Gläubiger は Insolvenzedikt (Ediktsdatei) に定める Anmeldefrist 内に Forderungsanmeldung を zuständiges Landesgericht へ提出する。Anmeldefrist は通常 allgemeine Prüfungstagsatzung の14日前に終わる (概ね6〜8週間)。Prüfungstagsatzung で Insolvenzverwalter が anerkannt/bestritten を判断。期限後の nachträgliche Anmeldung は Schlussrechnungstagsatzung の14日前まで可能だが €50+USt の費用 (besondere Prüfungstagsatzung) を要する (早期提出が不可能だった場合を除く) (Insolvenzordnung (IO) §§ 102 ff. (Anmeldung) + Insolvenzedikt (Anmeldefrist))
- 提出方法・控えの保管。不安があれば: Verfahrenshilfe (法律扶助) / Rechtsanwaltskammer erste anwaltliche Auskunft
