# Proof of debt (債権者側・清算・アイルランド) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 proof of debt を liquidator へ提出
【件名】   Proof of debt (債権者側・清算・アイルランド) に対する proof of debt

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【proof of debt を liquidator へ提出 (本人可; prepayment・deposit・gift voucher など前払金も debt: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Proof of debt: 清算人 (liquidator) が書面通知で証明期限を定める — 通知日から28日以上後でなければならない; 期限内に証明しない債権者は、その債権が証明される前になされた配当の利益から除外される。裁判所は債権者の申立てにより期限を延長できる (Companies Act 2014 s.674(1)-(3) (延長: s.674(4)))
- 提出方法・控えの保管。不安があれば: FLAC (Free Legal Advice Centres) / Citizens Information
