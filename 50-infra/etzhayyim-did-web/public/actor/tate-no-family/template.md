## 提出前チェック
- Tilsvar / mekling: foreldretvist (fast bosted・samvær・foreldreansvar の争い) を court に提起する前に obligatorisk mekling (familievernkontor) を経て meklingsattest (有効期間6か月) を得る必要がある (barneloven §51)。stevning が届いたら saksøkte は tingretten が定める期限 (通常3週間, tvisteloven §9-3) 内に tilsvar を提出。tingretten は conflict-and-reconciliation model で扱い、子に関し専門家 (心理士等) を任命することが多い。重大な暴力・虐待の有罪がある場合は meklingsattest なしでも提訴可 (barneloven §51 (mekling) + tvisteloven §9-3 (tilsvar))
- 提出方法・控えの保管。不安があれば: fri rettshjelp (法律扶助) / Forbrukerrådet / Forbrukertilsynet
