# 行政処分の通知 (許認可取消・課税処分等) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 審査請求書の提出
【件名】   行政処分の通知 (許認可取消・課税処分等) に対する 審査請求書の提出 (教示記載の審査庁へ)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【審査請求書の提出 (教示記載の審査庁へ)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- 審査請求: 処分があったことを知った日の翌日から起算して3月以内 (行政不服審査法18条1項)
- 取消訴訟: 処分があったことを知った日から6箇月以内 (行政事件訴訟法14条1項)
- 提出方法・控えの保管。不安があれば: 法テラス 0570-078374 / 地元弁護士会の法律相談
