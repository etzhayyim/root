# Demanda de desahucio (立退き・住居・スペイン) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 oposición を10日以内に
【件名】   Demanda de desahucio (立退き・住居・スペイン) に対する oposición

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【oposición を10日以内に (justicia gratuita の指定弁護士は申請で停止効も)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
⚠ Oposición: demanda de desahucio への oposición は10日 (días hábiles) 以内 — 無応答は審理なく lanzamiento (退去執行) の日程へ進む高速手続 (LEC arts. 440.3・441)
- Enervación (滞納の解消): 賃料滞納型は期限内の全額支払 (enervación) で1回に限り手続を解消できる場合がある (LEC art. 22.4)
- 提出方法・控えの保管。不安があれば: justicia gratuita (Ley 1/1996) / Colegio de Abogados (turno de oficio)
