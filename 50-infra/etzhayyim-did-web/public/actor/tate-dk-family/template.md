# Forældremyndighed / samvær (家事・デンマーク) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 提出前チェック
- Familieretshuset / Familieretten への対応: forældremyndighed・barnets bopæl・samvær について不一致なら、まず必ず Familieretshuset に申立てる (Forældreansvarsloven)。Familieretshuset は børnesagkyndig rådgivning / konfliktmægling を offer し、当事者は møder に出席する。不一致が続けば事件は Familieretten (家事裁判所) へ送られる。出発点は fælles forældremyndighed の継続。Familieretshuset の決定 (samvær/bopæl/forældremyndighed) には受領から4週間以内に klage できる (Forældreansvarsloven (+ Familieretshuset/Familieretten 手続))
- 提出方法・控えの保管。不安があれば: retshjælp / advokatvagten (無料相談) / Forbrugerklagenævnet (Nævnenes Hus)
