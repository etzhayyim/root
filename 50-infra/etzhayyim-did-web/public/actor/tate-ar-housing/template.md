# Juicio de desalojo (住居・アルゼンチン) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```

【件名】   Juicio de desalojo (住居・アルゼンチン) に対する contestación + prueba

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【contestación + prueba を5日以内に提出 (intimación previa の有無・renta 計算・通知の適法性を確認)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —

4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Contestación de la demanda de desalojo: juicio sumarísimo de desalojo (falta de pago・vencimiento) では被告 (inquilino) は notificación から5日以内に contestación + prueba を提出。住居の falta de pago では訴提起前に CCyC art.1222 の intimación fehaciente (carta documento — WhatsApp/email/口頭は無効) が必須。通知だけで強制退去はできず、el lanzamiento は orden judicial (sentencia + ejecución) によってのみ (CPCCN (proceso sumarísimo de desalojo) + CCyC art. 1222 (intimación previa))
- 提出方法・控えの保管。不安があれば: patrocinio jurídico gratuito (大学・公的) / Defensa del Consumidor 0800-666-1518
