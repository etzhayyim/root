# Zahlungsbefehl / Betreibung (スイス) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Betreibungsamt へ Rechtsvorschlag
【件名】   Zahlungsbefehl / Betreibung (スイス) に対する Betreibungsamt へ Rechtsvorschlag (10日以内 — 受領時にその場で宣言も可)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Betreibungsamt へ Rechtsvorschlag (10日以内 — 受領時にその場で宣言も可)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
⚠ Rechtsvorschlag (異議): Zustellung から10日以内に Rechtsvorschlag (理由不要・口頭でも可) — これだけで手続が止まる; Betreibung は証拠不要で誰でも開始できるため、身に覚えがなければ必ず異議 (SchKG Art. 74)
- 提出方法・控えの保管。不安があれば: unentgeltliche Rechtspflege (法律扶助) / Schlichtungsbehörde
