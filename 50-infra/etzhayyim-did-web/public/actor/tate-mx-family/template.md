# Contestación de demanda de divorcio (家事・メキシコ) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 contestación を期限内に提出
【件名】   Contestación de demanda de divorcio (家事・メキシコ) に対する contestación

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【contestación を期限内に提出 (請求への認否 + reconvención があれば併せて)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Contestación: juicio oral familiar では demandado は emplazamiento から9 días hábiles 以内に contestación を提出 (CNPCF art.665); 後に audiencia preliminar が15日内に設定される。CNPCF は2023施行だが州ごとに declaratoria で段階適用 — 採用済みの州のみ、未採用州は当該州の CPC を確認 (Código Nacional de Procedimientos Civiles y Familiares art. 665)
- 提出方法・控えの保管。不安があれば: PROFECO (消費者保護庁) / CONDUSEF (金融消費者)
