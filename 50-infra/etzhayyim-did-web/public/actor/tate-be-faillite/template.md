# Déclaration de créance (債権者側・倒産・ベルギー) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 déclaration de créance を RegSol 経由で curateur へ提出
【件名】   Déclaration de créance (債権者側・倒産・ベルギー) に対する déclaration de créance

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【déclaration de créance を RegSol 経由で curateur へ提出 (本人可; acompte・caution・bon d'achat など前払金も créance: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Déclaration de créance / aangifte van schuldvordering: 破産判決 (jugement déclaratif de faillite, RegSol + Moniteur belge 公告) が定める期限内に déclaration de créance を RegSol 電子登録簿経由で curateur へ提出; 届出権は破産判決から1年で時効消滅し、期限後の届出はその間に既に命じられた配当を受けられない (Code de droit économique Livre XX, art. XX.155)
- 提出方法・控えの保管。不安があれば: bureau d'aide juridique (pro deo) / SPF Économie (consommateurs)
