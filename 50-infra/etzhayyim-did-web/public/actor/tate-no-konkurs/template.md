# Konkurs hos motpart (債権者側・倒産・ノルウェー) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【bostyrer へ fordring を anmeld (forskudd・gavekort も債権: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —

## 提出前チェック
- Fordringsanmeldelse: 債権は bostyrer へ anmeld — Brønnøysund 公告記載の frist 内に (遅延届出も審査され得るが配当リスク) (konkursloven §109 以下)
- 提出方法・控えの保管。不安があれば: fri rettshjelp (法律扶助) / Forbrukerrådet / Forbrukertilsynet
