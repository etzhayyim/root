# Written statement to a matrimonial petition (家事・インド) — 自己対応チェックリスト

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

本物の書類の経路: summons は court officer / registered post (CPC Order V) — WhatsApp/SMS の『court』通知は偽
SMS/メールのみの『裁判所』通知は接触せず: tasuke 助 (サイバー犯罪被害支援) / cybercrime.gov.in / 1930 helpline / local police

## 期限 (起算点=送達日を自分で確認)
- **Written statement**: summons 送達から30日以内に written statement (各 allegation の認否) を Family Court へ提出 (CPC Order VIII Rule 1); 30日徒過時は理由を記録の上90日まで延長可。Family Court は和解 (reconciliation) 重視で柔軟に延長することがあるが、未提出は ex parte 手続 (Order VIII Rule 10) になりうる (CPC 1908 Order VIII Rule 1 + Family Courts Act 1984 (matrimonial) — 要改正確認)

## 選択肢 (member 本人が決めて提出する — 代理はしない)
🛡 written statement (認否 + 抗弁) を Family Court へ提出 (ex parte decree の回避)
- Family Court の reconciliation/調停 に出席 (合意の余地)
