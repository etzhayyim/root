# Eviction before the Rent Authority/Court (住居・インド) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Rent Authority/Court へ reply を期間内に提出
【件名】   Eviction before the Rent Authority/Court (住居・インド) に対する Rent Authority/Court へ reply

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Rent Authority/Court へ reply を期間内に提出 (事由・rent 計算・通知の適法性を争う)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Reply to the eviction application: 出租人は退去を求めるため Rent Authority / Rent Court に申立てる必要があり、警察や force による直接退去はできない。被申立人 (tenant) は通知/Authority が定める期間内に reply を提出 (Model Tenancy Act の3層 Rent Authority→Rent Court→Rent Tribunal、原則60日内に裁定)。退去は Authority/Court の eviction order によってのみ; landlord は essential supply/service を停止できない。州ごとに Rent Control Act が異なり Model Tenancy Act 2021 の adoption も州依存 — 通知記載と当該州法を確認 (Model Tenancy Act 2021 + state Rent Control Acts)
- 提出方法・控えの保管。不安があれば: District Legal Services Authority (NALSA 無料法律扶助) / State Bar Council
