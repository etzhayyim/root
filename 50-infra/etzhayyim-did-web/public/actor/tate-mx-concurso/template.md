# Reconocimiento de créditos (acreedor・concurso・メキシコ) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 solicitud de reconocimiento de créditos を conciliador へ提出
【件名】   Reconocimiento de créditos (acreedor・concurso・メキシコ) に対する solicitud de reconocimiento de créditos

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【solicitud de reconocimiento de créditos を conciliador へ提出 (本人可; anticipo・depósito・vale など前払金も crédito: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Solicitud de reconocimiento de créditos: sentencia de concurso mercantil の DOF (Diario Oficial de la Federación) 公告から20 días naturales 以内に conciliador へ solicitud de reconocimiento de créditos を提出 (art.122 frac.I); その後 lista provisional への objeción 期間・reconocimiento 判決への apelación 期間という後続2機会があるが、frac.III の期間経過後は債権の reconocimiento を求められない (Ley de Concursos Mercantiles art.122)
- 提出方法・控えの保管。不安があれば: PROFECO (消費者保護庁) / CONDUSEF (金融消費者)
