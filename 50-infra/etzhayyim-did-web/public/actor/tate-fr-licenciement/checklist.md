# Lettre de licenciement (解雇・労働・フランス) — 自己対応チェックリスト

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

本物の書類の経路: injonction de payer / assignation は commissaire de justice (旧 huissier) による signification
SMS/メールのみの『裁判所』通知は接触せず: tasuke 助 (サイバー犯罪被害支援) / cybermalveillance.gouv.fr / France Victimes 116 006

## 期限 (起算点=送達日を自分で確認)
- **Contestation (prud'hommes)**: licenciement の通知から12か月以内に conseil de prud'hommes へ異議 (本人可) (Code du travail L.1471-1 — 要改正確認)
- **Précision des motifs**: 通知から15日以内に理由の明確化を請求できる (後の争いで理由が固定される) (Code du travail L.1235-2 — 要改正確認)

## 選択肢 (member 本人が決めて提出する — 代理はしない)
- lettre recommandée で motifs の précision を請求 (15日)
🛡 conseil de prud'hommes へ saisine (12 mois — 自分の雇用・補償を守る防御)
