# 終止租約 / 返還房屋 (住居・台湾) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 終止事由・通知期間の適法性を確認し書面で反論
【件名】   終止租約 / 返還房屋 (住居・台湾) に対する 終止事由・通知期間の適法性

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【終止事由・通知期間の適法性を確認し書面で反論 (点交期日にも対応)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- 終止租約への対応: 出租人の提前終止は法定事由 (修繕拒否・賃料2か月分の遅延+催告・無断転貸 等) + 終止30日前の書面通知が必要。通知だけで強制退去はできず、房屋の返還は當事者共同の點交による (一方が催告後も応じなければ點交完了とみなす)。房客が争うなら事由・通知の適法性を確認し点交期日に対応 (租賃住宅市場發展及管理條例 第10條 (出租人提前終止))
- 提出方法・控えの保管。不安があれば: 法律扶助基金會 (Legal Aid Foundation) / 各地律師公會
