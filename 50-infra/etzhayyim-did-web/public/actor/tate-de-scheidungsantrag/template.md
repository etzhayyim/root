# Scheidungsantrag (家事・ドイツ) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Verfahrenskostenhilfe
【件名】   Scheidungsantrag (家事・ドイツ) に対する Verfahrenskostenhilfe (訴訟費用扶助) の申請は本人可 — 資力がなくても弁護士

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Verfahrenskostenhilfe (訴訟費用扶助) の申請は本人可 — 資力がなくても弁護士を立てられる】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Anwaltszwang (弁護士強制): Familiensachen は Familiengericht で弁護士強制 — 申立てに対抗する手続行為は本人では行えない (単に同意するだけなら自分の弁護士不要の場合あり); tate が雛形を出せない管轄類型であることを正直に開示 (FamFG §114)
- 提出方法・控えの保管。不安があれば: Verbraucherzentrale / örtliche Rechtsanwaltskammer
