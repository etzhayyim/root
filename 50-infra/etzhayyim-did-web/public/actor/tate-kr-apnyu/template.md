# 채권압류 및 추심명령 (給与差押え・執行・韓国) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 압류금지채권 범위변경 신청
【件名】   채권압류 및 추심명령 (給与差押え・執行・韓国) に対する 압류금지채권 범위변경 신청 (생계 곤란 시 — 法定の権利)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【압류금지채권 범위변경 신청 (생계 곤란 시 — 法定の権利)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- 즉시항고: 압류명령 송달부터 1주 이내に즉시항고 가능 (手続違背) (민사집행법 15조・227조)
- 압류금지 범위 (생계 보호): 급여は1/2까지만 압류 가능 + 월 185만원 (最低生計費・시행령 기준) 이하は全額 압류금지 — 生活維持分は法律上守られている (민사집행법 246조・동 시행령)
- 提出方法・控えの保管。不安があれば: 대한법률구조공단 (Korea Legal Aid, 132) / 소비자상담센터 1372
