# Eviction notice (notice to quit, 住居・米国) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 unlawful detainer が提起されたら answer を期限内に提出
【件名】   Eviction notice (notice to quit, 住居・米国) に対する unlawful detainer が提起されたら answer

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【unlawful detainer が提起されたら answer を期限内に提出 (期限は極端に短い — 例 CA 10日)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- 通知期間 (州法): 通知種別 (pay-or-quit / cure-or-quit / no-fault) と日数は州法による — 期限内の支払/是正で多くは解消 (例 CA 3-day pay-or-quit) (州 landlord-tenant law (例 Cal. CCP §1161))
- 強制退去の発生時点: 強制退去は unlawful detainer 訴訟 + 裁判所命令 + sheriff によってのみ — self-help eviction (鍵交換・電気停止) はほぼ全州で違法 (州法 (例 Cal. Civ. Code §789.3))
- 提出方法・控えの保管。不安があれば: state bar lawyer-referral service / Legal aid (lsc.gov)
