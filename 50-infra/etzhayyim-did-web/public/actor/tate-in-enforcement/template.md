# Attachment of salary (賃金差押え・執行・インド) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 免除
【件名】   Attachment of salary (賃金差押え・執行・インド) に対する 免除 (最初の₹1,000 + 残額の2/3)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【免除 (最初の₹1,000 + 残額の2/3) を超える attachment には court へ objection を提出 (Order XXI)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Salary attachment への対応: decree の execution で salary を attach する場合 (Order XXI Rules 48/48A)、最初の ₹1,000 と残額の2/3 は attachment から免除され、attachable なのは (salary − ₹1,000) の1/3 のみ (maintenance decree を除く)。さらに同一 attachable 部分が通算24か月 attach されたら12か月免除、同一 decree では24か月で最終免除。免除超過は court で異議できる (CPC 1908 s.60(1) proviso + Order XXI Rules 48 & 48A)
- 提出方法・控えの保管。不安があれば: District Legal Services Authority (NALSA 無料法律扶助) / State Bar Council
