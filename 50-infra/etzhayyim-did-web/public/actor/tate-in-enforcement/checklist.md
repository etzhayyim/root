# Attachment of salary (賃金差押え・執行・インド) — 自己対応チェックリスト

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

本物の書類の経路: summons は court officer / registered post (CPC Order V) — WhatsApp/SMS の『court』通知は偽
SMS/メールのみの『裁判所』通知は接触せず: tasuke 助 (サイバー犯罪被害支援) / cybercrime.gov.in / 1930 helpline / local police

## 期限 (起算点=送達日を自分で確認)
- **Salary attachment への対応**: decree の execution で salary を attach する場合 (Order XXI Rules 48/48A)、最初の ₹1,000 と残額の2/3 は attachment から免除され、attachable なのは (salary − ₹1,000) の1/3 のみ (maintenance decree を除く)。さらに同一 attachable 部分が通算24か月 attach されたら12か月免除、同一 decree では24か月で最終免除。免除超過は court で異議できる (CPC 1908 s.60(1) proviso + Order XXI Rules 48 & 48A — 要改正確認)

## 選択肢 (member 本人が決めて提出する — 代理はしない)
🛡 免除 (最初の₹1,000 + 残額の2/3) を超える attachment には court へ objection を提出 (Order XXI)
🛡 attach 部分が (salary−₹1,000) の1/3 上限・24か月 cap を超えていないか employer/court で確認
