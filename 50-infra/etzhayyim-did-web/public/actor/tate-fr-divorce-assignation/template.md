# Assignation en divorce (家事・フランス) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【aide juridictionnelle の申請は本人可 (loi 91-647) — 資力がなくても avocat を立てられる】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —

4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Constitution d'avocat (弁護士必須): divorce contentieux は avocat による代理が必須 — 本人では対抗手続不能 (DE Anwaltszwang と同型); tate が雛形を出せない管轄類型であることを正直に開示 (CPC art. 1108 以下 / loi du 23 mars 2019)
- 提出方法・控えの保管。不安があれば: point-justice (France Services) / aide juridictionnelle
