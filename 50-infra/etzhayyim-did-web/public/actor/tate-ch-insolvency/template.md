# Forderungseingabe (債権者側・倒産・スイス) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 Forderungseingabe を Konkursamt へ書面提出
【件名】   Forderungseingabe (債権者側・倒産・スイス) に対する Forderungseingabe

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【Forderungseingabe を Konkursamt へ書面提出 (本人可; Anzahlung・Kaution・Gutschein など前払金も Forderung: kaiyaku 縁-ledger と突合)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Forderungseingabe: Konkurseröffnung 後、Konkursamt は Schuldenruf を SHAB / 官報に公告し、Gläubiger に書面の Forderungseingabe を呼びかける (SchKG Art. 232)。期限は公告から1か月 (30日)。証拠書類を添付する (不十分なら Konkursamt が追加提出期限を設定 or 却下しうる)。有効な債権は Kollokationsplan で確定し20日間縦覧され、不服は20日以内に Kollokationsklage で争える。期限後の遅延 Eingabe も可能だが追加費用は債権者負担で、既了の中間配当には与れない (SchKG Art. 232 (Schuldenruf, 1 Monat) + Art. 244-250 (Kollokationsplan))
- 提出方法・控えの保管。不安があれば: unentgeltliche Rechtspflege (法律扶助) / Schlichtungsbehörde
