# Lønindeholdelse / udlæg (賃金差押え・執行・デンマーク) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 trækket が rådighedsbeløb
【件名】   Lønindeholdelse / udlæg (賃金差押え・執行・デンマーク) に対する trækket が rådighedsbeløb (日常費+boligudgifter)

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【trækket が rådighedsbeløb (日常費+boligudgifter) を侵害するなら Gældsstyrelsen/fogedret へ見直し/klage を申立て】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Lønindeholdelse / udlæg への対応: 公的債務 (税・SU・住宅手当・自治体請求) は Gældsstyrelsen が skattekort の trækprocent を上げて lønindeholdelse する。ただし skyldner は日常費 + 固定 boligudgifter のための rådighedsbeløb を必ず保持でき、これを超える部分のみ控除される (gældsinddrivelsesbekendtgørelsen で算定)。私的債権者 (銀行等) は lønindeholdelse できず fogedret 経由の udlæg のみで、生活に必要な trangsbeneficium (retsplejeloven §509) は差押え免除。算定に異議があれば Gældsstyrelsen/fogedret に klage できる (gældsinddrivelsesbekendtgørelsen (rådighedsbeløb) + retsplejeloven §509 (trangsbeneficium))
- 提出方法・控えの保管。不安があれば: retshjælp / advokatvagten (無料相談) / Forbrugerklagenævnet (Nævnenes Hus)
