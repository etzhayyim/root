# Divorce application (家事・豪州) — 自己対応チェックリスト

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

本物の書類の経路: statement of claim は personal service / 州規則による郵送 (例 NSW UCPR Part 10)
SMS/メールのみの『裁判所』通知は接触せず: tasuke 助 (サイバー犯罪被害支援) / Scamwatch (ACCC) / ReportCyber (cyber.gov.au)

## 期限 (起算点=送達日を自分で確認)
- **Response to divorce**: 国内送達なら送達から28日以内 (海外42日) に response — no-fault (12か月 separation) のため離婚自体の争点は限定; 財産 (property) ・子 (parenting) は別手続 (Family Law Act 1975 s.48 / FCFCOA (Family Law) Rules 2021 — 要改正確認)

## 選択肢 (member 本人が決めて提出する — 代理はしない)
🛡 Response to divorce をオンライン提出 (28日 — 異議は管轄・separation 期間等)
- property settlement は離婚確定から12か月以内の別申立て — 期限に注意
