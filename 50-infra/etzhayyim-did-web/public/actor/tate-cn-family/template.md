# 答辩状 (家事・離婚訴訟・中国) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 答辩状 を人民法院へ提出
【件名】   答辩状 (家事・離婚訴訟・中国) に対する 答辩状

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【答辩状 を人民法院へ提出 (各请求の認否 + 证据 — 管辖异议があれば同時に)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- 答辩状: 起诉状副本の受領から15日以内に答辩状を人民法院へ提出 (中国国内に住所のない被告は30日); 管辖异议も同じ答辩期間内に提出。答辩しなくても審理は進む (欠席でも判決されうる) (中华人民共和国民事诉讼法 第128条 (答辩期))
- 提出方法・控えの保管。不安があれば: 法律援助 (法律援助法・12348 公共法律服务热线) / 消费者协会 12315
