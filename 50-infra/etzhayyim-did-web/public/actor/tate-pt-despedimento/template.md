# Comunicação de despedimento (解雇・労働・ポルトガル) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## まず公式様式を確認
- formulário de impugnação を tribunal へ (60日 — apoio judiciário 併用可) — **公式様式が存在します。自由書式より様式を優先**してください。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 formulário de impugnação を tribunal へ
【件名】   Comunicação de despedimento (解雇・労働・ポルトガル) に対する formulário de impugnação

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【formulário de impugnação を tribunal へ (60日 — apoio judiciário 併用可)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
⚠ Impugnação judicial: ação de impugnação は despedimento から60日以内; 効力停止 (suspensão de despedimento) を求めるなら5日 (úteis) 以内 — 極端に短い (Código do Trabalho arts. 386・387)
- 提出方法・控えの保管。不安があれば: apoio judiciário (Segurança Social 経由の法律扶助) / Ordem dos Advogados
