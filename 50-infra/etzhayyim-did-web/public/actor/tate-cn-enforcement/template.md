# 扣留・提取収入 (賃金差押え・執行・中国) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

【自分の氏名・住所・連絡先】

## 提出前チェック
- 执行 (扣留・提取収入) への対応: 执行通知 受領後に履行しないと人民法院は履行すべき部分について収入を扣留・提取できる (民诉法243条; 协助执行通知書で雇用主・銀行等が協力)。ただし被执行人及びその扶養家族の生活必需費用は必ず保留される (当該地の最低生活保障标准で算定、扶養家族分も考慮)。保留額を侵害する執行には法院へ执行异议 (225条) を申立てられる (中华人民共和国民事诉讼法 第243条 (扣留・提取 + 生活必需费用保留))
- 提出方法・控えの保管。不安があれば: 法律援助 (法律援助法・12348 公共法律服务热线) / 消费者协会 12315
