# Oppsigelse (解雇・労働・ノルウェー) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 書面で forhandlinger を請求
【件名】   Oppsigelse (解雇・労働・ノルウェー) に対する 書面で forhandlinger

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【書面で forhandlinger を請求 (2 uker — まず期限と stå i stilling を確保)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
⚠ Forhandlinger (協議請求): oppsigelse を争う forhandlinger の請求は2 uker 以内 — 在職継続権 (stå i stilling) の起点にもなる (arbeidsmiljøloven §17-3)
- Søksmål (提訴): 無効 (ugyldighet) の søksmål は8 uker 以内・erstatning のみなら6か月以内 (forhandling 終了から起算) (arbeidsmiljøloven §17-4)
- 提出方法・控えの保管。不安があれば: fri rettshjelp (法律扶助) / Forbrukerrådet / Forbrukertilsynet
