# Attachment order (賃金差押え・執行・ニュージーランド) — 提出書面の雛形 (記入式)

> 一般的な法情報であり個別の法的助言ではありません (非裁定/UPL)。期限の起算点 (送達日) は必ず自分で確認し, 重要な判断は記載の無料相談窓口・専門家へ。法令は改正されます — アンカーは現行条文で要確認。

> この雛形は member 本人が【 】を埋めて確定・提出するための構造テンプレートです。

## 自由書式の構造 (様式がない/補助書面の場合)

```
【提出先】 返済困難なら court へ deduction 額の variation を申立て
【件名】   Attachment order (賃金差押え・執行・ニュージーランド) に対する 返済困難なら court へ deduction 額の variation

【自分の氏名・住所・連絡先】
【相手方/事件の特定】 事件番号・通知の日付: 【受領した書面の番号と日付】

1. 私は【通知を受領した日 — 期限の起算点】に標記の通知を受領しました。
2. 私は次のとおり申し立てます: 【返済困難なら court へ deduction 額の variation を申立て (protected earnings rate=net の60% を下回らせない)】
3. 理由: 【簡潔に。理由不要の手続き (異議のみで足りる類型) は省略可 —
   checklist.md の期限ルール参照】
4. 添付書類: 【受領通知の写し・証拠など】

【日付】 【署名】
```

## 提出前チェック
- Attachment order への対応: judgment 後に creditor/debtor が attachment order を申立てると employer が salary/wages から控除する。ただし debtor は net income (税引後) の60% (protected earnings rate) を必ず保持でき、控除は net の40%を超えられない。返済が困難なら court に控除額の variation を申立てられる (District Court Act 2016 s.157 (attachment orders) + protected earnings rate 60% net)
- 提出方法・控えの保管。不安があれば: Community Law Centres (無料) / Citizens Advice Bureau NZ
