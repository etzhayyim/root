手続きと期限

Verzoekschrift echtscheiding (家事・オランダ)

  • ⚠ Verweerschrift (advocaat 必須): verweerschrift は原則6週間以内 — ただし家事は **advocaat による提出が必須** (本人不可の類型; gesubsidieerde rechtsbijstand で立てられる); 子がいれば ouderschapsplan が要件 (Rv 815-816 / Wet op de rechtsbijstand — 要改正確認)
  • 🛡 gesubsidieerde rechtsbijstand (toevoeging) の申請は本人可 — 資力に応じ advocaat が付く
  • mediation 併用で共同 verzoek への転換も
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 即 advocaat (提出必須) / kokoro 心 (精神的サポート)

Opzegging arbeidsovereenkomst (解雇・労働・オランダ)

  • ⚠ Verzoekschrift (vervaltermijn — 失権期間): instemming なき opzegging への vernietiging / billijke vergoeding の verzoekschrift は2か月以内 (kantonrechter) — vervaltermijn のため停止・中断なし (BW 7:686a lid 4 — 要改正確認)
  • Transitievergoeding: transitievergoeding の請求は雇用終了から3か月以内 (同じく vervaltermijn) (BW 7:673 / 7:686a lid 4 sub b — 要改正確認)
  • 🛡 kantonrechter へ verzoekschrift (2か月 — kanton は本人可)
  • vaststellingsovereenkomst へのサインは検討期間 (14日撤回権) を確認してから
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Juridisch Loket (無料) / kokoro 心 (精神的サポート)

Loonbeslag (賃金差押え・執行・オランダ)

  • Beslagvrije voet (差押禁止最低額): beslagvrije voet (生活維持最低額) は2021年法で自動計算され必ず手元に残る — 計算の基礎データ誤り (世帯構成等) は deurwaarder へ是正請求 (Wet vereenvoudiging beslagvrije voet / Rv 475da — 要改正確認)
  • 🛡 beslagvrije voet の計算根拠 (uwbeslagvrijevoet.nl) を確認 — 誤りは是正される
  • gemeente の schuldhulpverlening (無料の債務支援)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 多重債務 → Wsnp/Msnp の検討

Faillissement wederpartij (債権者側・倒産・オランダ)

  • Indiening ter verificatie: 債権は curator へ ter verificatie に提出 — 期限は verificatievergadering の公告/レターで確認 (遅延は原則締切) (Faillissementswet artt. 108-110 — 要改正確認)
  • 🛡 vordering を curator へ提出 (前払金・tegoed も債権: kaiyaku 縁-ledger と突合)
  • insolventieregister で curator/期日を確認
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 担保 (pand/hypotheek) → advocaat

Opzegging huurovereenkomst (住居・オランダ)

  • 同意しない自由 (huurbescherming): verhuurder の opzegging だけでは賃貸借は終了しない — 賃借人が6週間以内に書面で同意しない限り, verhuurder は kantonrechter の判断を求めるしかない (同意する義務はない) (BW 7:272 — 要改正確認)
  • 🛡 同意しない (沈黙でも借家権は続く — 裁判所が判断するまで居住継続)
  • opzeggingsgrond (dringend eigen gebruik 等) の妥当性を !WOON 等で点検
  • 🛡 鍵交換・追い出しは違法 — ontruiming は vonnis + deurwaarder のみ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: kantonrechter 手続 → Juridisch Loket / huurteam

Dagvaarding (呼出状・オランダ)

  • Verschijnen / antwoord (出頭・答弁): dagvaarding 記載の roldatum (期日) までに出頭または schriftelijk antwoord (kanton ≤€25,000 は本人可) (Rv art. 111 (dagvaarding の必要的記載事項) — 要改正確認)
  • conclusie van antwoord を提出 (認否 + 反論)
  • roldatum に出頭 (verstek = 欠席判決の回避)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: €25,000 超 (advocaat 必須域)

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)
