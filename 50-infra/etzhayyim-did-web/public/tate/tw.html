台灣 — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「支付命令・起訴状は法院の送達 — LINE/SMS の『法院』通知は偽 (165 へ)」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / 165 反詐騙專線 / 警政署 110

手続きと期限

離婚調解/訴訟の通知 (家事・台湾)

  • 調解前置: 離婚等の家事事件は**調解前置** — 通知記載の調解期日に出席 (無断欠席は調解に代わる裁定・過料があり得る); 合意するまで成立しない (家事事件法 23條・32條 — 要改正確認)
  • 🛡 調解期日に出席して言い分を述べる (程序監理人・社工の同席請求も可)
  • 答辯状・意見書を事前提出
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 法律扶助基金會 (家事は扶助対象) / kokoro 心 (精神的サポート)

資遣/解僱通知 (解雇・労働・台湾)

  • 事由の法定性: 解僱は勞基法11條 (資遣 — 預告期間+資遣費) / 12條 (懲戒 — 知った時から30日内) の法定事由に限る — 事由なき解僱は無効主張の余地 (勞動基準法11條・12條・16條・17條 — 要改正確認)
  • 🛡 勞資爭議調解を労工局へ申請 (無料・本人可 — 確認僱傭關係/資遣費)
  • 非自願離職證明書を요구 (失業給付の前提)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 訴訟段階 → 法律扶助基金會 / kokoro 心 (精神的サポート)

強制執行 (薪資扣押・執行・台湾)

  • 薪資 1/3 限度 (生計保護): 薪資の強制執行は各期 1/3 を限度とし, 債務人と共同生活親属の**最低生活費は差押え不可** — 超過は声明異議 (強制執行法 115-1條・122條 — 要改正確認)
  • 🛡 1/3 超過・最低生活費侵害は声明異議 (強制執行法12條)
  • 分期清償の協議
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 更生/清算 (消費者債務清理條例) → 法律扶助基金會

支付命令 (支払督促・台湾)

  • 異議 (不変期間): 支付命令の送達後20日の不変期間内に異議 (→ 通常/簡易訴訟へ) (台湾民事訴訟法516條 — 要改正確認)
  • 異議状を発令法院へ提出 (理由不要)
  • 請求に理由がある場合: 支払い/和解
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: NT$500,000 超 (簡易訴訟の上限域)

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • 全部免責 (概不負責) — 消費者保護法12條 (定型化契約條款 違反誠信原則は無効) / 民法247條之1
  • 自動續約 (自動更新) — 消保法11條之1 (審閲期間) / 定型化契約應記載及不得記載事項 — 業種別告示を確認
