手続きと期限

Scheidungsklage (家事・オーストリア)

  • Klagebeantwortung / 期日: Bezirksgericht の指定に従い応答・出頭 — **einvernehmliche Scheidung (§55a EheG, 半年別居+合意) への転換が最も低負担**; 争訟型は Verschulden が財産・扶養に影響 (EheG §49・§55a / ZPO — 要改正確認)
  • 🛡 合意できるなら §55a 転換 (両者で申立て — 弁護士なしも可)
  • Klagebeantwortung (Verfahrenshilfe 可)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Familienberatung (無料) / Rechtsanwalt / kokoro 心 (精神的サポート)

Kündigung (解雇・労働・オーストリア)

  • ⚠ Anfechtung (ArbVG): sozialwidrig/motivwidrig な Kündigung の Anfechtung は Arbeits- und Sozialgericht へ2 Wochen 以内 — 極端に短い; Betriebsrat の有無で手続が変わる (ArbVG §105 (3)-(4) — 要改正確認)
  • 🛡 即 AK (Arbeiterkammer) へ — 労働者は無料の法的代理を受けられる
  • ASG へ Anfechtung (2 Wochen)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: AMS (失業給付) 即登録 / kokoro 心 (精神的サポート)

Gehaltsexekution (賃金差押え・執行・オーストリア)

  • Existenzminimum (生計保護): **unpfändbares Existenzminimum** (扶養で増額) は必ず手元に残る — 雇用主が表で自動計算; 誤りや事情変更は Exekutionsgericht へ (EO §291a 以下 (Existenzminimum-Verordnung) — 要改正確認)
  • 🛡 Existenzminimum 表との一致を確認 (AK が無料で再計算してくれる)
  • 扶養・疾病による増額を Exekutionsgericht へ申立て
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Schuldenberatung (公的・無料)

Gerichtliche Aufkündigung (住居・オーストリア)

  • ⚠ Einwendungen: MRG 適用住居の賃貸人解約は**裁判所経由 (gerichtliche Aufkündigung) のみ** + §30 の列挙事由限定 — Einwendungen は送達から4 Wochen 以内 (MRG §30・§33 — 要改正確認)
  • 🛡 Einwendungen を4週間以内に (理由は後で補える — まず期限を守る)
  • Mietervereinigung / AK の住宅相談
  • 🛡 鍵交換等は besitzstörung — Räumung は判決+Gerichtsvollzieher のみ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Verfahrenshilfe

Zahlungsbefehl (支払命令・オーストリア)

  • Einspruch (異議): Zustellung から4週間以内に Einspruch (→ 通常手続へ) (österr. ZPO §248 (Mahnverfahren) — 要改正確認)
  • Einspruch を発令裁判所へ提出 (理由不要)
  • 請求に理由がある場合: 支払い/和解
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 高額・渉外要素 → Rechtsanwalt

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)
