Suomi — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「haaste は haastemies / postitse の tiedoksianto — SMS の『käräjäoikeus』通知は偽」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / poliisi (nettipetokset 通報) / kuluttajaneuvonta

手続きと期限

Vuokrasopimuksen irtisanominen (住居・フィンランド)

  • Irtisanomissuoja (解約保護): 賃貸人の irtisanominen には正当事由が必要 — 借家人は käräjäoikeus に無効 (julistettava tehottomaksi) を求められる; 通知には事由記載が必須 (AHVL (laki asuinhuoneiston vuokrauksesta) 56-57§§ — 要改正確認)
  • 🛡 正当事由を欠く場合は無効の kanne (oikeusapu 併用可)
  • 🛡 鍵交換等は違法 — häätö は ulosottomies のみ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Vuokralaiset ry (借家人協会) / kuluttajaneuvonta

Irtisanominen (解雇・労働・フィンランド)

  • Kanneaika (出訴期間): perusteeton irtisanominen の korvaus 請求は työsuhteen päättymisestä 2 vuotta 以内 (työsopimuslaki 13 luku 9§ — 要改正確認)
  • 🛡 liitto (組合) + työttömyyskassa へ即連絡 (給付と法的支援)
  • käräjäoikeus へ kanne (oikeusapu 併用可)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: oikeusapu / liitto の弁護士 / kokoro 心 (精神的サポート)

Palkan ulosmittaus (賃金差押え・執行・フィンランド)

  • Suojaosuus (保護部分): **suojaosuus (日額×扶養人数の保護部分) は必ず残り**, 原則として手取りの1/3まで — vapaakuukaudet (差押え休止月) も請求できる (ulosottokaari 4 luku 48§・52-53§§ — 要改正確認)
  • 🛡 suojaosuus の計算を確認 (扶養の申告; oikaisu は ulosottomies へ)
  • vapaakuukaudet (休止月) を申請
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: talous- ja velkaneuvonta (無料の公的債務相談)

Haastehakemus (簡易訴状・フィンランド)

  • Vastaus (答弁): 呼出記載の期限内に vastaus — 無応答は yksipuolinen tuomio (欠席判決) (oikeudenkäymiskaari 5 luku — 要改正確認)
  • vastaus を käräjäoikeus へ (認否 + 反論)
  • 請求に理由がある場合: 支払い/sovinto
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 高額・複雑 → oikeusapu

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • 全部免責 (vastuunrajoitus) — kuluttajansuojalaki 3 luku (kohtuuttomat sopimusehdot)
  • jatkuu automaattisesti (自動継続) — KSL / kuluttaja-asiamies の自動継続ガイドライン (事前通知・容易な解約導線)

無料相談: oikeusapu (julkinen 法律扶助) / kuluttajaneuvonta (KKV 消費者助言)
