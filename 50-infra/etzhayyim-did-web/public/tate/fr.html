France — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「injonction de payer / assignation は commissaire de justice (旧 huissier) による signification」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / cybermalveillance.gouv.fr / France Victimes 116 006

手続きと期限

Injonction de payer (支払命令・フランス)

  • Opposition (異議): signification (commissaire de justice による送達) から1か月以内に opposition (Code de procédure civile art. 1416 — 要改正確認)
  • 発令裁判所の greffe へ opposition を提出 (→ 対審手続へ)
  • 請求に理由がある場合: 支払い/échéancier の交渉
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: €10,000 超 (représentation par avocat 義務域)

Assignation en divorce (家事・フランス)

  • Constitution d'avocat (弁護士必須): divorce contentieux は avocat による代理が必須 — 本人では対抗手続不能 (DE Anwaltszwang と同型); tate が雛形を出せない管轄類型であることを正直に開示 (CPC art. 1108 以下 / loi du 23 mars 2019 — 要改正確認)
  • 速やかに avocat へ (audience d'orientation 前に)
  • 🛡 aide juridictionnelle の申請は本人可 (loi 91-647) — 資力がなくても avocat を立てられる
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 即時に avocat (représentation obligatoire) / kokoro 心 (精神的サポート)

Lettre de licenciement (解雇・労働・フランス)

  • Contestation (prud'hommes): licenciement の通知から12か月以内に conseil de prud'hommes へ異議 (本人可) (Code du travail L.1471-1 — 要改正確認)
  • Précision des motifs: 通知から15日以内に理由の明確化を請求できる (後の争いで理由が固定される) (Code du travail L.1235-2 — 要改正確認)
  • lettre recommandée で motifs の précision を請求 (15日)
  • 🛡 conseil de prud'hommes へ saisine (12 mois — 自分の雇用・補償を守る防御)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: défenseur syndical / avocat (複雑な経済的解雇)

Congé du bailleur (住居・フランス)

  • Congé の有効要件: bailleur の congé は期間満了の6か月前まで + 理由 (vente / reprise / motif légitime) と形式が必須 — 不備は無効; 高齢・低資力の locataire は保護 (Loi 89-462 art. 15 — 要改正確認)
  • 退去義務の発生時点: expulsion は juge + commissaire de justice によってのみ; trêve hivernale (冬季) は執行停止 — 通知のみで退去不要 (CPCE L.412-6 (trêve hivernale) — 要改正確認)
  • congé の形式・理由・期限を点検 (ADIL 無料相談)
  • vente の場合は droit de préemption (優先買取権) を確認
  • 🛡 鍵交換・追い出しは違法 (voie de fait) — expulsion は裁判所経由のみ; 受けたら police / ADIL へ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: assignation en expulsion が届いた場合

Saisie-attribution (口座差押え・執行・フランス)

  • Contestation: dénonciation から1か月以内に juge de l'exécution へ contestation (CPCE R.211-11 — 要改正確認)
  • Solde bancaire insaisissable (SBI): 口座には SBI (RSA 単身者額) が申請不要で自動的に残される — 生活維持分は守られている (CPCE R.162-2 — 要改正確認)
  • 🛡 SBI が残されているか口座を確認 (自動 — 不足なら銀行へ是正請求)
  • JEX へ contestation (1か月以内)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 多重債務 → commission de surendettement (Banque de France・無料)

Procédure collective (債権者側・倒産・フランス)

  • ⚠ Déclaration de créance: BODACC 公告から2か月以内 (国外債権者は+2か月) に mandataire judiciaire へ déclaration — 徒過は forclusion (失権; relevé de forclusion は例外的) (Code de commerce L.622-24・R.622-24 — 要改正確認)
  • 🛡 déclaration de créance を期限内に (オンライン可) — 前払金・avoir も債権 (kaiyaku 縁-ledger 突合)
  • BODACC 公告日を確認 (起算点)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 担保付き・高額 → avocat

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • responsabilité の全面排除 (clause noire) — Code de la consommation L212-1 / R212-1 6° (réparation du préjudice — liste noire, réputée non écrite)
  • reconduction tacite (黙示更新) — Code de la consommation L215-1 (loi Chatel — 更新前通知義務; 不履行なら随時解約可)
