日本 — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「裁判所の書類は特別送達 (郵便職員手渡し・受領印)」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / 警察相談専用電話 #9110 / 消費者ホットライン 188

手続きと期限

支払督促 (簡易裁判所)

  • ⚠ 督促異議の申立て: 支払督促の送達を受けた日から2週間以内 (経過後も仮執行宣言送達から2週間は申立て可) (民事訴訟法391条・393条 — 要改正確認)
  • 🛡 督促異議申立書を発した簡易裁判所へ提出 (→ 通常訴訟へ移行)
  • 請求に理由がある場合: 支払い/分割の相談 (書面で)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 請求額が大きい / 仮執行宣言後・強制執行の予告がある

少額訴訟の呼出状 (60万円以下)

  • 答弁書の提出: 呼出状に記載された裁判所指定の期限まで (欠席は擬制自白のリスク) (民事訴訟法159条・254条 — 要改正確認)
  • 通常訴訟への移行申述: 最初の口頭弁論期日において弁論をするまで (民事訴訟法373条 — 要改正確認)
  • 少額訴訟判決への異議: 判決書等の送達を受けた日から2週間以内 (民事訴訟法378条 — 要改正確認)
  • 答弁書の提出 (言い分・証拠を整理)
  • 通常訴訟への移行申述 (反訴・控訴が必要な場合)
  • 期日に出頭して陳述 (一期日審理)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 反訴を検討する / 事実関係が複雑

訴状の送達 (通常訴訟)

  • 答弁書の提出: 呼出状に記載された裁判所指定の期限まで (欠席+答弁書なし → 欠席判決) (民事訴訟法159条3項・254条 — 要改正確認)
  • 答弁書の提出 (請求の認否 + 抗弁)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 請求額が大きい / 常に弁護士相談を強く推奨 (本訴は高リスク)

行政処分の通知 (許認可取消・課税処分等)

  • 審査請求: 処分があったことを知った日の翌日から起算して3月以内 (行政不服審査法18条1項 — 要改正確認)
  • 取消訴訟: 処分があったことを知った日から6箇月以内 (行政事件訴訟法14条1項 — 要改正確認)
  • 審査請求書の提出 (教示記載の審査庁へ)
  • 聴聞・弁明の機会への対応 (通知に従う)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 営業停止など重大処分 / 税務 → 税理士/弁護士

解雇通知/解雇予告 (労働・日本)

  • 解雇理由証明書の請求: 請求すれば使用者は遅滞なく交付義務 — 理由の確定が全ての応答の起点 (労働基準法22条 — 要改正確認)
  • 賃金請求権の消滅時効: 未払賃金の請求権は3年で時効 (当分の間) — 異議・交渉は早いほど良い (労働基準法115条 — 要改正確認)
  • 🛡 解雇理由証明書を書面で請求 (労基法22条)
  • 解雇に異議を留めて撤回交渉 (承諾と誤解される言動を避ける)
  • 総合労働相談コーナー/あっせん/労働審判の検討 (自分の雇用を守る防御)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 解雇無効を本格的に争う (労働審判・訴訟) → 弁護士/法テラス / 未払賃金が高額

賃貸借の解約申入れ/更新拒絶 (住居・日本)

  • 賃貸人からの解約申入れの要件: 6か月前の申入れ + 正当事由が必要 — 通知だけで退去義務は生じない (借地借家法27条・28条 — 要改正確認)
  • 法定更新: 期間満了後も使用を継続し賃貸人が遅滞なく異議を述べなければ法定更新 (借地借家法26条 — 要改正確認)
  • 正当事由・立退料提示の有無を確認 (28条は立退料を考慮要素とする)
  • 賃料は払い続ける (受領拒否なら供託) — 債務不履行を作らない
  • 🛡 自力救済 (鍵交換・荷物搬出・追い出し) は違法 — 強制退去は裁判所の明渡判決+執行のみ; 受けたら警察・弁護士へ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 明渡訴訟を起こされた場合 / 立退料交渉が高額

債権差押命令 (給与・預金, 執行・日本)

  • 執行抗告: 差押命令の送達から1週間以内に執行抗告が可能 (民事執行法10条2項 — 要改正確認)
  • 差押禁止の範囲 (生活保護): 給与は手取りの3/4が差押禁止 (33万円を超える部分は別) — 生活維持分は法律上守られている (民事執行法152条 — 要改正確認)
  • 🛡 生活が困難なら差押禁止債権の範囲変更を申立て (民執153条) — 法定の権利であり債務逃れではない
  • 手続違背があれば執行抗告 (1週間以内)
  • 債務全体の整理を検討 (任意整理/特定調停) — 財産隠しは違法 (N3): 権利行使と隠匿は別物
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 複数債権者からの差押え / 債務整理 → 弁護士/司法書士/法テラス

破産手続開始の通知 (債権者側・倒産・日本)

  • 債権届出: 債権届出期間は開始決定で裁判所が定める (通知記載) — 期間内に届け出ないと配当から漏れ得る (一般調査期間後の届出は制限) (破産法31条・111条 — 要改正確認)
  • 🛡 債権届出書を提出 — 前払金・預け金・未消化サブスク・ポイントも債権 (kaiyaku 縁-ledger と突合)
  • 少額なら配当見込みと手間を比較して判断
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 高額債権 / 別除権・相殺が絡む場合

家事調停の期日通知 (家事・日本)

  • 期日への出頭: 通知記載の調停期日に出頭 (正当な理由のない不出頭は5万円以下の過料があり得る) — 出頭困難なら期日変更を早めに申し出る (家事事件手続法51条・258条 — 要改正確認)
  • 期日に出頭 (調停は話合いの場 — 合意するまで成立しない)
  • 🛡 答弁書・事情説明書を事前提出 (言い分を整理)
  • 出頭困難なら期日変更の申出 (電話会議の可否も確認)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 財産分与・親権・養育費が争点 → 弁護士/法テラス / kokoro 心 (精神的サポート — 家事事件は Wellbecoming 負荷が大きい)

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • 自動更新 + 狭い解約通知窓 — 民法548条の2第2項 (定型約款・不当条項の組入制限)
  • 過大な中途解約違約金 — 消費者契約法9条1号 (平均的な損害を超える部分)
  • 年14.6%超の遅延損害金 — 消費者契約法9条2号 (年14.6%を超える部分)
  • 事業者の全部免責 — 消費者契約法8条 (損害賠償責任の全部免除条項)
  • 一方的変更権 (裁量変更) — 消費者契約法10条 / 民法548条の4 (定型約款の変更要件)
  • 専属的合意管轄 (遠隔地) — 消費者契約法10条 (一方的に害する条項) — 司法判断が分かれる類型
  • リボルビング払い自動設定 — 割賦販売法30条の2の3 (書面交付・表示義務) — 手数料総額の確認
  • 支払停止の抗弁の放棄 — 割賦販売法30条の4 (支払停止の抗弁 — 片面的強行規定; 適用には政令金額要件)
  • 年会費の自動課金 (無利用でも) — — (適法だが kaiyaku 縁-ledger の休眠カード退会候補)
  • 無限定の損害賠償 (片務) — 民法90条 (公序良俗) — B2B は消費者契約法の保護なし; 上限条項の相互化を交渉
  • 広汎な競業避止義務 — 民法90条 / 独禁法 (拘束条件付取引) — 期間・地域・代償の相当性
  • 長期支払サイト — 下請法2条の2 (受領後60日以内の支払期日) — 適用は資本金区分による
  • 成果物知財の包括譲渡 (無償) — 下請法4条2項3号 (不当な経済上の利益の提供要請) / 独禁法 優越的地位の濫用
