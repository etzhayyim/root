Deutschland — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「Mahnbescheid/Klage は förmliche Zustellung (gelber Umschlag, ZPO §166 ff.)」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / Polizei Onlinewache / Verbraucherzentrale

手続きと期限

Mahnbescheid (支払督促・ドイツ)

  • Widerspruch (異議): 送達から2週間以内の Widerspruch が原則 (経過後も Vollstreckungsbescheid 発令まで可; 発令後は2週間以内の Einspruch) (ZPO §692・694・700 — 要改正確認)
  • 同封の Widerspruch 用紙で異議 (→ 通常訴訟へ)
  • 請求に理由がある場合: 支払い/分割の交渉
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Vollstreckungsbescheid が既に出ている

Kündigung (解雇通知・労働・ドイツ)

  • ⚠ Kündigungsschutzklage (解雇無効確認): Kündigung の到達 (Zugang) から3週間以内に Arbeitsgericht へ提訴 — 徒過すると解雇は有効と擬制される (最重要短期期限) (KSchG §4・§7 — 要改正確認)
  • 形式要件: Kündigung は書面必須で電子形式は無効 — email/SMS のみの解雇通知は形式無効の疑い (書面を要求) (BGB §623 — 要改正確認)
  • 🛡 Kündigungsschutzklage を Arbeitsgericht へ (1. Instanz は弁護士強制なし — 自分の雇用を守る防御)
  • Betriebsrat への異議申立て (BetrVG §102)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 3週間期限は絶対 — 迷ったら即 Rechtsantragstelle/弁護士へ

Kündigung des Mietverhältnisses (住居・ドイツ)

  • Widerspruch (Sozialklausel): 賃貸借終了の2か月前までに書面で Widerspruch (Härtefall — 高齢・疾病・代替住居困難など) (BGB §574・§574b — 要改正確認)
  • Kündigung の要件: 賃貸人の Kündigung は berechtigtes Interesse (例 Eigenbedarf) + 書面 + 理由記載が必要 — 不備は無効主張の余地 (BGB §573・§568 — 要改正確認)
  • 書面で Widerspruch を賃貸人へ (期限内)
  • Eigenbedarf 等の理由の真実性を点検 (Mieterverein 相談)
  • 🛡 鍵交換等は verbotene Eigenmacht (BGB §858) で違法 — Räumung は判決+執行官のみ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: Räumungsklage が提起された場合 / Mieterverein / Rechtsanwalt

Konto-/Lohnpfändung (執行・ドイツ)

  • P-Konto への転換 (口座保護): 口座を P-Konto (Pfändungsschutzkonto) に転換すれば月額 Grundfreibetrag が自動的に保護される — 転換は銀行へ請求 (差押え後でも可) (ZPO §850k・§850c — 要改正確認)
  • Erinnerung (執行異議): 執行処分の方式違背には Erinnerung を申立て可能 (ZPO §766 — 要改正確認)
  • 🛡 銀行に P-Konto 転換を請求 (書式は銀行所定 — 法定の権利)
  • Erinnerung を執行裁判所へ (§766 ZPO)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 多重債務 → Schuldnerberatung (公的債務相談・無料)

Insolvenzeröffnung (債権者側・倒産・ドイツ)

  • Forderungsanmeldung: Eröffnungsbeschluss の定める期間内に Insolvenzverwalter へ債権を anmelden (遅延届出も可だが追加費用) (InsO §28・§174 — 要改正確認)
  • 🛡 Forderungsanmeldung を Verwalter へ (書式は通知同封 — 本人可; Gutschein・前払金も債権: kaiyaku 縁-ledger と突合)
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 担保・相殺・高額債権

Scheidungsantrag (家事・ドイツ)

  • Anwaltszwang (弁護士強制): Familiensachen は Familiengericht で弁護士強制 — 申立てに対抗する手続行為は本人では行えない (単に同意するだけなら自分の弁護士不要の場合あり); tate が雛形を出せない管轄類型であることを正直に開示 (FamFG §114 — 要改正確認)
  • 速やかに Fachanwalt für Familienrecht へ (対抗には必須)
  • 🛡 Verfahrenskostenhilfe (訴訟費用扶助) の申請は本人可 — 資力がなくても弁護士を立てられる
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 即時に弁護士 (Anwaltszwang) / kokoro 心 (精神的サポート)

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • 短期の一方的値上げ条項 — BGB §309 Nr.1 (kurzfristige Preiserhöhung — AGB Klauselverbot)
  • 過大な損害賠償の定額化 — BGB §309 Nr.5 (Pauschalierung von Schadensersatzansprüchen)
