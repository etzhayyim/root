Danmark — 受け取った法的通知への応答ガイド

詐欺通知の見分け方: 本物の書類の経路は「betalingspåkrav は fogedretten から (forkyndelse) — SMS/e-mail の『retten』通知は偽」。疑わしい場合は送信者に接触せず: tasuke 助 (サイバー犯罪被害支援) / politi 114 / Forbrug.dk

手続きと期限

Opsigelse af lejemål (住居・デンマーク)

  • ⚠ Indsigelse (異議): **6 uger 以内に書面で indsigelse すると, 賃貸人が boligretten へ提訴しない限り opsigelse は効力を持たない** (通知に異議教示の記載義務 — 不備は無効) (lejeloven §§ 176・182 系 — 要改正確認)
  • 🛡 書面 indsigelse を6 uger 以内に (教示記載の有無も点検)
  • 🛡 鍵交換等は違法 — udsættelse は fogedretten のみ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: LLO (Lejernes Landsorganisation)

Opsigelse (解雇・労働・デンマーク)

  • Usaglig opsigelse: funktionær (勤続1年以上) は usaglig opsigelse の godtgørelse を請求可 — 異議は組合/afskedigelsesnævn ルートが主で期限は労使協約による (協約上は短いことがある — 即組合へ) (funktionærloven §2b / hovedaftalen — 要改正確認)
  • 🛡 即 fagforening (組合) へ — DK は協約ルートが標準; a-kasse 登録も同時に
  • godtgørelse の根拠 (勤続・理由) を整理
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: 非組合員 → advokat / retshjælp / kokoro 心 (精神的サポート)

Konkurs hos modpart (債権者側・倒産・デンマーク)

  • Anmeldelse af krav: 債権は kurator へ anmeld — Statstidende の proklama/公告に記載の frist 内に (遅延は審査・配当から漏れ得る) (konkursloven §128 系 — 要改正確認)
  • 🛡 kurator へ krav を anmeld (forudbetaling・gavekort も債権: kaiyaku 縁-ledger と突合)
  • 元従業員なら **Lønmodtagernes Garantifond** (賃金保証基金) へ
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: pant/担保 → advokat

Betalingspåkrav (支払督促・デンマーク)

  • Indsigelse (異議): påkrav 記載の期限 (通常14日) 内に書面で indsigelse — 無応答は判決同等の効力 (påtegning) (retsplejeloven kap. 44a (§477a 以下) — 要改正確認)
  • fogedretten へ indsigelse (→ 通常手続へ)
  • 請求に理由がある場合: 支払い/分割
  • DL: チェックリスト · データ (JSON) · case actor profile
  • 相談先: kr. 50,000 超 (småsager 上限外)

契約の不利条項パターン (非裁定 — 可能性の指摘のみ)

  • 全部免責 (ansvarsfraskrivelse) — aftaleloven §36・§38c (urimelige aftalevilkår — 調整・無効)
  • forlænges automatisk (黙示更新) — forbrugeraftaleloven §28 (拘束5か月経過後は1か月通知で解約可 — 長期ロックは効かない)
