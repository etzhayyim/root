# PoC — the browser kotoba node as the sovereign apex tier-2 (ADR-2606013600)

Proves that actor resolution (the backing for `did.json` + `app.bsky.actor.getProfile`)
can run **entirely in the browser** on the real etzhayyim actor set — no server pull,
no vendor edge in the trust path. The kotoba node IS the browser; the only durable
thing to host is commodity IPFS pinning.

The read engine is `kotoba-wasm` (`40-engine/kotoba/crates/kotoba-wasm`): `kotoba-kqe`
EAVT/AEVT/AVET/VAET + CID-verified Prolly traversal compiled to `wasm32`, plus
client-side `ed25519` commit signing (no-server-key) and an IndexedDB block store.

## Run it

```sh
cd 50-infra/etzhayyim-did-web/poc-browser-node
npm ci                 # playwright-core only (no browser download)
npm run build          # build wasm bundles from the kotoba submodule + assemble serve/
npm run verify:node    # Node-driven proof on the REAL 28-actor SSoT
npm run verify:browser # real Google Chrome (channel: chrome) via the Service Worker
```

`npm run build` needs the kotoba submodule populated
(`git submodule update --init --recursive 40-engine/kotoba`) and the **rustup** stable
toolchain with the wasm32 target (`rustup target add wasm32-unknown-unknown`).
**Do not use Homebrew rust** — it lacks the wasm32 std (`core/std` E0463).

## What each file does

| file | role |
|---|---|
| `build-bundle.sh` | builds the node (`wasm-bindgen --target nodejs`) + web (`wasm-pack --target web`) bundles from the submodule, assembles a self-contained `serve/` |
| `gen-actor-datoms.mjs` | converts the REAL `00-contracts/schemas/actor-profile-seed.kotoba.edn` → `:yoro.profile/*` `seed-datoms.json` (the same shape the apex tier-2 `kg.entity` serves) |
| `resolve-actors.node.mjs` | Node harness: `loadDatoms` → `searchActors("kamado")` + `commitSigned` + content-address determinism (9 asserts) |
| `browser.spec.mjs` | playwright-core drives `serve/demo.html` in system Chrome; the `kotoba-sw.js` Service Worker answers `searchActors` from the in-browser wasm node (`x-kotoba-sw: local-wasm`) — 4 asserts + screenshot |

Built artifacts (`node-pkg/`, `serve/`, `node_modules/`) are git-ignored and
regenerated by `npm run build` (no git-lfs blobs).
