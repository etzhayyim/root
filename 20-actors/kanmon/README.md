# kanmon 関門

入試 (entrance-exam) **observatory** — a kotoba-Datom-native KG-mirror of the high-stakes
entrance-exam systems of **China, Korea, and Japan**. It mirrors the *public structure* of
each exam (制度 / 倍率 / 配点 / 出題区分) and computes, on read, an edge-primary
**barrier-load** — how exclusively a single exam gates access to opportunity — then routes the
most exclusive gates to concrete **openings**: alternative admission pathways, disclosure of
opaque criteria, reducing one-shot/one-day life-gating, and flagging access disparity.

> 関門 = a barrier gate. kanmon maps the gate **in order to open it** — never to help one
> person jump it, and never to rank anyone. It is an *observatory*, not an exam-prep service
> (that role, charter-clean, is its sibling **指南 shinan**), and it holds no representation of
> any individual examinee.

Status: **R0** (clj-native, synthetic/representative seed; tests green). See `CLAUDE.md` for
the gate algebra, the structural prohibitions, and run commands; `ADR-2606291500` for the design.
