# 20-actors/magatama

Magatama runtime root.

Layout:

- `sdk/magatama-host-sdk`: TypeScript host SDK
- `hosts/magatama-kami-host`: native KAMI host
- `hosts/magatama-desktop-host`: desktop host scaffold
- `inference/magatama-inference`: Rust inference runtime
- `config/magatama-config`: shared Rust config crate
