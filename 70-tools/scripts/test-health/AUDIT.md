## Cleanup guidance

- A `:different` shadow is a CANDIDATE, not an auto-fix: which of `.clj`/`.cljc` is canonical is the actor owner's call (the uchiwake fix removed `.clj` only after the `.cljc` port proved complete via a green suite). Verify per-actor: remove the stale side, run the suite, keep only if green.
