## The 5 axes

### Axis 1 — deps.toml book-keeping (cycle 27-30 + 46 markers)

**Source-of-truth**: code/docs paths referenced by `deps.toml` entries.
**Sidecar**: `deps.toml` itself (no separate file).
**Verifier**: `70-tools/scripts/lint/verify_deps_toml_paths.py`

```bash
# Default — full repo audit:
python3 70-tools/scripts/lint/verify_deps_toml_paths.py

# Scoped to one ADR:
python3 70-tools/scripts/lint/verify_deps_toml_paths.py --filter ADR-2605262500

# Machine output:
python3 70-tools/scripts/lint/verify_deps_toml_paths.py --json
```

**Marker convention** (cycle 46): paths intentionally missing carry
`(reserved)` or `(deferred-rename)` suffix:

```toml
[[adrs]]
path = "90-docs/adr/2605250730-tatekata-r1.md (reserved)"
# → owner-asserted future-impl; CI exits 0

[[modules]]
path = "00-contracts/lexicons/ai/gftd/apps/unispsc (deferred-rename)"
# → intentionally pre-cutover per CLAUDE.md root §"Do Not"; CI exits 0
```

**Exit codes**:
- `0` = no bare drift (accepted-reserved + stale-marker counts may be nonzero)
- `1` = at least one bare missing path (no marker) — **PR-gate fails**
- `2` = usage / parse error

**Failure modes**:
- `[modules] path = "foo/bar.py"` but file removed → add `(reserved)` if intentional, or delete entry
- Marker present but path now exists → drop the marker (stale-marker warning)

## Pre-commit hygiene

Cycle 51 had a 3-retry commit dance due to pre-existing trailing
whitespace + missing final newlines in `.md` files. Avoid by running
locally before commit:

```bash
# Strip trailing whitespace from all staged files:
for f in $(git diff --cached --name-only); do
  [ -f "$f" ] && sed -i '' 's/ *$//' "$f"
done

# Ensure all staged files end in newline:
for f in $(git diff --cached --name-only); do
  if [ -s "$f" ] && [ "$(tail -c1 "$f" | xxd -p)" != "0a" ]; then
    printf '\n' >> "$f"
  fi
done

git add -u
```

Pre-commit hooks (`trailing-whitespace` + `end-of-file`) are
grep-based, not auto-fix. `🥊` glyph in lefthook output = hook FAILED.

## Common failure modes — fix recipes

### "registry drift detected: disk=X entries, file=Y entries"

```bash
python3 70-tools/scripts/docs/regen-registry.py
git add 90-docs/_registry/docs.json
git commit --amend --no-edit   # or new commit
```

### "graph.jsonld drift detected"

```bash
python3 70-tools/scripts/docs/regen-graph-jsonld.py
git add 90-docs/_registry/graph.jsonld
```

### "deps.toml path audit: N bare drift"

Either:
- Restore the missing file/dir, OR
- Add `(reserved)` / `(deferred-rename)` marker to the path, OR
- Remove the `[[adrs]]` / `[[modules]]` entry

### "schema validation failed (N violations)"

```bash
# Get JSON detail:
python3 70-tools/scripts/docs/validate-registry-schemas.py --json | python3 -m json.tool

# Or human:
python3 70-tools/scripts/docs/validate-registry-schemas.py
# Lists which .md entry / field is wrong
```

Fix the source `.md` front-matter to conform to schema. Re-run axis 2
+ axis 3 to regenerate.

### "magatama manifest validation failed"

```bash
python3 70-tools/scripts/docs/validate-magatama-manifests.py --json
# Lists which app / field is wrong
```

Fix `60-apps/<app>/magatama.jsonld` to conform to `magatama.schema.json`.

### jsonschema not installed locally

```bash
python3 -m pip install --break-system-packages jsonschema
# Or use a venv / uv environment
```

Without jsonschema, axes 4 + 5 skip with a warning. CI installs it
unconditionally so PR will catch the issue.
