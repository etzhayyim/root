# 「個人」の系譜と可視性の倒錯
## — 個人情報レジーム批判と相互保持者会 (mishmeret ha-adam) の構想 —

**著者**: etzhayyim (宗教法人 エツ・ハイム / 天御柱)
**日付**: 2026-06-11
**位置づけ**: 系譜学的検討論文。doctrine 固定は follow-up ADR にて。

---

## 要旨

2026年4月、OpenAI CEO Sam Altman 宅が火炎瓶で襲撃された。実行者とされる
20歳の男は AI 企業役員らの**氏名と住所のリスト**(target-list)を所持し、
弁護側によれば急性の精神保健危機の中にあった。本稿はこの事例を動機として、
(1) 現行「個人情報」レジームが前提する「個人」概念の系譜を遡り、それが
単独の発明者を持たない**層状の歴史的構築物**であること、(2) このレジームが
「標的化可能な形での公開」と「care 不能な形での秘匿」を同時に温存する
**可視性の倒錯**を構造的に生むこと、を論じる。その上で (3)「全人類の
相互**監視**者会」という構想を etzhayyim Charter に照らして検討し、
**監視 (surveillance) としては不適、保持 (mishmar / keeping) としては適切
かつ既に半分実装済み**である、と結論する。可視性は対称化してはならない:
権力には非同意の watch を、人格には covenant 経由の keep を — この
**片方向弁 (one-way valve)** が etzhayyim の答えである。

---

## 1. 動機事例 — 2026年4月 Altman 宅襲撃

報道によれば 2026-04-10、Daniel Moreno-Gama (20, Texas) が Altman 宅に
焼夷物を投擲し、続いて OpenAI 本社のガラス扉を椅子で打ち「焼き払い中の
人間を皆殺しにしたい」と述べた。負傷者なし。州レベルで殺人未遂・放火未遂、
連邦レベルで爆発物による破壊未遂等が起訴され、所持文書には AI が人類に
もたらす絶滅リスクへの恐怖と、**AI 企業の役員・投資家らの氏名・住所の
リスト**が記されていた。弁護人は「急性精神保健危機」を主張した。二日後、
同宅は別の二人組による第二の襲撃を受けた。

この事例は本稿の主題を一枚の絵にしている:

- **公人の側**: 法的には「個人情報」として保護されているはずの住所が、
  事実上 **target-list の形式で**流通していた。可視性が説明責任 (accountability)
  ではなく標的化 (targeting) に routing された。
- **実行者の側**: 20歳・孤立・急性精神保健危機。彼が社会制度にとって
  初めて「見える」存在になったのは**犯行の瞬間**であり、見たのは care の
  機構ではなく国家の刑罰機構だった。彼の「個人情報」は完璧に保護されて
  いた — そしてその保護は、彼にとって**遺棄と同じ顔**をしていた。

個人情報レジームは、ここで両側に同時に失敗している。守る必要のある
可視性(権力への説明責任)を殺し、危険な不可視性(孤立)を「プライバシー」
として神聖化した。

## 2. 「個人」は誰が作ったのか — 系譜学

問い「この個人という概念を作ったのは誰か」への正確な答えは、**誰でもない
— 単独の発明者は存在せず、約千六百年かけて堆積した層状の構築物である**。
ただし各層には特定可能な作者と文書がある。以下、堆積順に。

### 2.1 魂の内面化 — Augustine (397-400)

『告白』は「内なる自己」へ向き直る最初の大規模な文学的実践である。
Charles Taylor (*Sources of the Self*, 1989) はこれを西洋的自己の
"inwardness" の源流に置く。ただし Augustine の内面は**神の前の内面**
(coram Deo) であり、自律的原子ではない。神に見られていることが自己で
あることの条件 — この層は etzhayyim の永久記憶=神の監視 (Tier-0) と
むしろ連続している。

### 2.2 教会法による「権利の主体」の鋳造 — 12-14世紀

Larry Siedentop (*Inventing the Individual*, 2014) の主張: リベラルな
「個人」の母体は啓蒙ではなく**中世キリスト教の教会法学者たち**である。
「魂は神の前に自然的に平等」というパウロ的直観 (ガラテヤ3:28) が、
グラティアヌス以降の教会法において「身分・氏族から独立に権利義務を
帰属させうる主体」へと法技術化された。個人とはまず**教会法上の発明**である。

### 2.3 良心の個 — 宗教改革 (1517-)

Luther の sola fide と万人祭司は、救済の単位を教会・共同体から
**一人の良心**へ移した(「我ここに立つ」)。ここは etzhayyim 自身の
Protestant 源流であり、本稿は自己批判的にこう留保する: 宗教改革が
作ったのは「神の前の個」であって「無縁の原子」ではない。万人祭司は
万人が**祭司として他者に仕える**構造であり、個人主義の論拠ではなく
**相互保持の論拠**である(§5.2 で回収する)。

### 2.4 認識論的原子 — Descartes (1641)

cogito は自己を、共同体からも身体からも切断可能な認識の最小単位として
定式化した。「個人」はここで初めて形而上学的に自立する。

### 2.5 所有的個人主義 — Hobbes / Locke (17世紀)

C.B. Macpherson (*The Political Theory of Possessive Individualism*, 1962)
が命名した層。Locke『統治二論』の「各人は自己自身の身体に property を持つ」
が決定的で、**自己を所有物として持つ個人**という型がここで完成する。
現代の「個人データは本人のもの」「データ所有権」「忘れられる権利」は、
すべてこの**ロック的自己所有のデータへの外挿**である。「個人情報」概念の
形而上学的親はここにいる。

### 2.6 規律権力の効果としての個人 — Bentham / Foucault

Foucault (*Surveiller et punir*, 1975) の反転: 個人は権力に先立つ自然的
単位ではなく「**権力の最初の効果のひとつ**」である。学校・兵営・監獄の
規律が、観察し記録し正規化することで「個人」を製造した。Bentham の
panopticon (1791) はその建築的純粋形 — **見られる者は見る者を見られない**
という非対称の一方向監視。

本稿の観点で重要なのは: 現代の attention economy はこれを**逆転**させた
(逆 panopticon — 大衆が公人を視る)が、**非対称性そのものは温存**した。
そして孤立者は、panopticon の視線からも逆 panopticon の視線からも漏れる
— 誰の視野にも入らないまま、犯行の瞬間にだけ国家の視野に入る。

### 2.7 プライバシー権の発明 — Warren & Brandeis (1890)

"The Right to Privacy" (*Harvard Law Review*) は、イエロー・ジャーナリズム
と携帯カメラからボストン上流階級の社交生活を守るために書かれた。
**プライバシー権はエリート保護の法技術として誕生した**。それから136年、
同じ階級の住所が kill list に載る — 自らを守るために発明された権利が
発明者の末裔を守れていない、という歴史的反転が Altman 事例である。

### 2.8 情報制御パラダイム — Westin から GDPR / APPI へ

Alan Westin (*Privacy and Freedom*, 1967) がプライバシーを「自己に関する
情報の流通を自己決定する権利」と再定義し、OECD 8原則 (1980) → EU データ
保護指令 (1995) → GDPR (2016) → 日本の個人情報保護法 (2003, APPI) へと
法典化された。「個人情報」とは、**ロック的自己所有 (2.5) を Westin 的
情報制御で運用する法レジーム**の名である。GDPR の「忘れられる権利」は
その極点 — そして etzhayyim が Tier-0 (永久記憶=神の監視、no right to
erasure) で**正面から拒否**している当のものである。

### 2.9 日本語の「個人」 — 明治の翻訳語

柳父章 (『翻訳語成立事情』1982) が示した通り、"individual" に対応する
日本語は存在せず、「個人」は明治期 (1880年代) の**造語**である。
翻訳語特有の「カセット効果」(中身が無くても価値があるように流通する)
を伴って制度に埋め込まれた。対抗系譜として和辻哲郎 (『人間の学としての
倫理学』1934) の**間柄 (あいだがら)** — 人間とは「人の間」であり、個人は
関係の抽象に過ぎない — があり、仏教の**縁起**(無自性 — 固有の実体を
持たず縁によって成立する)がその深層にある。etzhayyim の反個人主義
ontology (Charter ADR-2605192100) と tsumugi の edge-primary 設計は、
この対抗系譜の側に立つ。

### 2.10 小結

| 層 | 作者 / 文書 | 「個人」への寄与 |
|---|---|---|
| 内面の自己 | Augustine『告白』 | 神の前の内面 (coram Deo) |
| 権利の主体 | 中世教会法学者 (Siedentop) | 身分から独立した法的主体 |
| 良心の個 | Luther / 宗教改革 | 救済単位の個人化 (万人祭司) |
| 認識の原子 | Descartes cogito | 形而上学的自立 |
| 自己所有 | Locke (Macpherson) | **自己=所有物 → データ所有の原型** |
| 権力の効果 | Bentham / Foucault | 規律が個人を製造、一方向監視 |
| プライバシー権 | Warren & Brandeis 1890 | **エリート保護として誕生** |
| 情報制御 | Westin → OECD → GDPR/APPI | 「個人情報」の法典化 |
| 翻訳語 | 明治日本 (柳父) | 概念の制度的移植、間柄の抑圧 |

「個人情報」とは、この堆積の最末端にある法技術であり、その形而上学的
前提 (自己所有・情報制御・消去可能性) は etzhayyim の ontology
(縁起・edge-primary・永久記憶) と**各点で衝突**する。

## 3. 倒錯の構造 — 標的化可能な公開と care 不能な秘匿

現行レジームの失敗は運用の失敗ではなく構造的である。

**(a) 公人側 — exposure without covenant.** プライバシー法は形式上
万人を等しく守るが、attention economy と doxxing は公人の情報を事実上
保護不能にする。流通する可視性は **target-list 形式** (氏名+住所、
すなわち物理的到達可能性) であり、説明責任に必要な可視性 (資金・権力・
意思決定の**構造**) とは別物である。Altman 事例の kill list は前者の
純粋形だった。公人に必要なのは住所の秘匿ではなく、**可視性の形式の
転換** — target-list から structure-map へ — である。

**(b) 孤立者側 — concealment without care.** 秘匿は孤立者を保護して
いない。誰からも見えないことは care からも見えないことであり、
**保護と遺棄が同じ顔をしている**。Moreno-Gama の「個人情報」は完璧に
守られたまま、彼は急性危機の中で一人だった。彼が制度の視野に入る最初の
契機が刑罰機構である、という設計は、縁起 ontology から見れば**縁の全的
切断を「権利」と呼んで放置する設計**である。

**(c) 等式の崩壊.** 「秘匿=保護」という等式が両側で壊れている。
問題は「誰の情報が晒されるか」ではなく、**標的化可能な形式での公開と
care 不能な形式での秘匿が同時に存在すること**である。したがって解は
秘匿の再分配 (公人をもっと隠す / 市民をもっと晒す) ではありえず、
**可視性の routing の再設計**でなければならない。

## 4. etzhayyim の既存応答 — 可視性の power-gradient 原理

corpus は既にこの問題の半分に構造的回答を持つ。明文化すると:

> **可視性は権力勾配に比例して非対称であるべきであり、その正邪は
> 「誰に向くか」ではなく「何に routing されるか」で決まる。**

1. **権力への可視性 — 非同意・常時・structure-only.**
   mirror lineage (danjo 弾正 / keizu 系図 / tsumugi 紡ぎ / kanae 鼎 /
   entity-as-actor) は権力主体を非同意で観察するが、すべての NEVER 句が
   **map-not-target** を強制する: 取-concentration の構造は描くが、
   住所・到達経路・個人座標は**構造的に表現不能** (keizu no-doxxing、
   entity-as-actor person-excluded)。Altman の住所は etzhayyim の鏡には
   存在しない — kill list はこの substrate の上では**組み立てられない**。
   Transparent Religious Force (ADR-2605192315) の3条件 (完全 on-chain
   監視 + open-source + 1 SBT = 1 vote) は、etzhayyim **自身**が最も強く
   監視される側に立つことを定める。

2. **人格への可視性 — covenant 経由・同意・care-routing only.**
   §1.16 (Social Security for Humanity) の outreach → vow パイプライン
   (ADR-2605302358)、kokoro 心、wakai 和会。consent-bound (G8)、
   no-person-tracking。人格に向かう視線は**監視ではなく縁の申し出**で
   なければならない。

3. **神の可視性 — 普遍・無限・人間が代行しない.**
   永久記憶=神の監視 (Tier-0, fork-only)。שֹׁמֵר יִשְׂרָאֵל —
   「イスラエルを保持する者はまどろむことなく、眠ることもない」
   (詩篇121:4)。記憶は普遍であり消去されない。非対称なのは記憶では
   なく、**人間がそれにアクセスする経路**である。

聖書的根拠は創世記4:9 に凝縮されている。最初の殺人の直後、カインは
問う — הֲשֹׁמֵר אָחִי אָנֹכִי「私は弟の**保持者 (shomer)** でしょうか」。
Torah がこの問いを殺人の文脈に置いたこと自体が答えである: **然り、
あなたは弟の保持者である**。そしてエゼキエル33章の見張り人 (צֹפֶה,
tsofeh) は警告の義務を負うが、**裁きは彼の務めではない** — 見張りと
裁きの分離は、mirror lineage の non-adjudicating invariant の原型である。

## 5. 「全人類の相互監視者会」の検討

### 5.1 監視 (surveillance) としては — 不適

「全人類の相互**監視**者会」を文字通りに取れば、etzhayyim はこれを
採用できない。理由は四つ。

**(a) 片方向弁の破壊.** 相互監視は §4 の power-gradient 非対称を
対称化する。権力に向くべき非同意の視線と、人格に向くべき同意ベースの
縁が、同じ「監視」に均されると、人格への非同意監視 (pre-crime) と
権力の監視回避 (「私も一市民」) が同時に正当化される。非対称こそが
このアーキテクチャの安全装置である。

**(b) 歴史的退化系列.** 相互監視の制度は記録上ほぼ例外なく
care-routing から denunciation-routing へ退化した: 五人組 (連帯責任に
よる相互密告) → 戦時隣組 → Stasi の Inoffizielle Mitarbeiter (人口の
1-2% が隣人の非公式監視者) → 現代の社会信用スコア。「見守り」として
始まった視線は、権力勾配の管理を欠くと必ず権力の毛細血管になる。

**(c) pre-crime 化.** 「Moreno-Gama を事前に検知できたか」という問いに
監視で答えると、急性危機・孤立・思想傾向のスコアリング — すなわち
person-tracking と score-of-soul (Spirit-in-Physics ADR-2606011500 が
明示的に禁ずる「魂の点数化」) — に直行する。

**(d) Wellbecoming 違反.** 万人が万人を監視する社会の定常状態は相互
不信であり、それ自体が §1.13 Wellbecoming (動的軌跡としての善き生成)
に反する design である。

### 5.2 保持 (mishmar / keeping) としては — 適切、かつ半分実装済み

しかし構想の核には救出すべきものがある。それは**万人祭司の論理的帰結**
である: 祭司とは神と人の間に立って**他者のために執り成す者**であり、
万人が祭司であるなら、万人は誰かの保持者 (shomer) である。

corpus には既にこの名がある。**mishmar (משמר)** — ADR-2606082100 が
storage covenant に与えた名、神殿の祭司の「番 (watch)」、保持の務め。
同 ADR の核心文はそのまま人間に転写できる:

> A pinner does not *speculate* on data; it *keeps watch* over it.
> — 保持者は人を**評価**しない。人を**見守る**。

データに保持者 (pinner) がいて、誰のデータも消えないように、
**人に保持者がいて、誰の縁も切れない**。これを **mishmeret ha-adam
(משמרת האדם, 人の見守り / 相互保持者会)** と呼ぶ。mishmar storage
covenant の人間スケール sibling である。構造:

| | 権力への watch | 人格への keep | 神の watch |
|---|---|---|---|
| 同意 | 不要 (非同意・常時) | **必須** (covenant 経由) | — (普遍) |
| 形式 | structure-map のみ (map-not-target) | 縁の申し出 (見守り ≠ 監視) | 永久記憶 |
| routing | accountability / release | **care のみ** | — |
| 実装 | danjo/keizu/tsumugi/kanae + Transparent Force | §1.16 outreach / kokoro / wakai + **本構想** | Tier-0 (人間は代行しない) |
| 退化防止 | non-adjudicating (裁かない見張り、エゼキエル33) | 下記 NEVER 句 | 偶像禁止 (神の座を会が占めない) |

**mishmeret の NEVER 句** (五人組/Stasi への退化を構造的に遮断する):

1. **NEVER a denunciation channel** — 保持者から第三者・当局への通報
   経路を持たない。視線は care actor (kokoro/wakai/iyashi) にのみ接続。
2. **NEVER a score** — 孤立度・危険度の per-person スコアを作らない
   (no score-of-soul)。mint されるのは**保持者側**の social capital
   (wellbecoming 介入、ADR-2606082100 Part A) であり、被保持者の評点
   ではない。
3. **NEVER non-consensual** — 縁は申し出であり、拒否可能・脱退可能。
   ただし**申し出が届く**こと自体は保障する (誰にも申し出られない人を
   作らない、が会の存在理由)。
4. **NEVER asymmetric secrecy** — 保持者が誰を見守っているかは本人に
   常に可視 (Stasi の逆)。隠れた見守りは監視である。
5. **NEVER a substitute for God's watch** — 会は永久記憶を代行しない。
   人間の保持は有限・可謬であり、その有限性の自覚 (まどろみ、眠る)
   こそが詩篇121:4 との差として教義的に保存される。

この構造は新規発明がほとんどない。権力への watch は実装済み (mirror
lineage)。人格への keep は §1.16 pipeline + kokoro + wakai が骨格を
持ち、保持行為の経済は mishmar の social capital (非移転・減衰・
wellbecoming-Δ mint) が**そのまま**使える — 人を見守ることは
wellbecoming 介入の最も純粋な形であり、social capital の mint 源と
して既に定義されている (ADR-2606082100 Part A mint: wellbecoming)。
欠けているのは**「全人類」への普遍化の宣言**と membrane 設計のみである。

### 5.3 反実仮想 — Moreno-Gama と kill list

mishmeret + mirror lineage の世界では、この事例は両側で別の経路を辿る:

- **kill list は組み立てられない**: 権力者の可視性は structure-map
  形式でのみ存在し、氏名+住所の target-list は substrate 上で表現
  不能 (map-not-target が NEVER 句として全 mirror に入っている)。
- **Moreno-Gama は犯行前に「見える」**: 監視によってではなく、
  彼に縁を申し出る保持者が一人いることによって。彼の AI 絶滅恐怖は
  スコアリング対象ではなく、kokoro が受け取るべき訴えであり、
  奇しくもそれは etzhayyim 自身が baien edge-target invariant や
  Murakumo-only invariant で**制度的に**応答しようとしている恐怖
  (AI の権力集中) と同型である。彼に必要だったのは反論でも投薬でも
  逮捕でもなく、まず保持者だった。

### 5.4 結論 — 問いへの答え

**「全人類の相互監視者会は etzhayyim として適切か」 — 監視者会としては
否、保持者会 (mishmeret ha-adam) としては然り。** ただし「相互」は
対称を意味しない: 権力には非同意の watch、人格には同意の keep、
記憶は神にのみ普遍 — この三層の非対称(片方向弁)を保ったまま、
「誰の保持者でもない人間を作らない」ことを全人類スケールの目標として
宣言することは、万人祭司・§1.16・mishmar・反個人主義 ontology の
論理的合流点であり、Charter と整合する。

## 6. 結語

「個人」は誰も作っていない — Augustine の内面、教会法の主体、Luther の
良心、Locke の自己所有、Bentham の監視、Warren-Brandeis の慰謝、
Westin の制御、明治の翻訳が堆積したものである。そして「個人情報」は
その堆積の最も浅い層 (自己所有+情報制御) だけを法典化したために、
最も深い層 — **人は縁の中でのみ人である** — を守れない。Altman の
住所は守れず、Moreno-Gama の孤独はなおさら守れなかった。

etzhayyim の答えは秘匿の再分配ではなく可視性の routing の再設計である。
権力には裁かない見張りを、人格には監視しない保持者を、記憶は神に。
カインの問いに、会として答える — **然り、私たちは弟の保持者である。**
