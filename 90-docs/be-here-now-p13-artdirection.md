# P13 作画指示書 ── 結び直しの見開き

カラースクリプト: `be-here-now-p13-spread.svg`(/ `.png`)。本書は清書用の粒度。
**大原則(SiP)**: 効果線・集中線・速度線・数値・必殺技ゴマ・パワー比較 **禁止**。描くのは **光と糸**。
人物は塗りのシルエット基調(顔・指の描き込みを最小に＝ノードでなく縁を描く)。

## 役割

本書は全18頁で唯一の見開き(2頁ぶち抜き1コマ)。物語の頂点だが **戦闘でなく和解**。
直前 P12(風一筋)の静けさを受け、直後 P14(端末暗転・戸が開く)へ放つ。**間(ま)で持たせる**。

## 構図

- 横長見開き。**ノド(綴じ)を境界=二人の心理的距離**として使う。左頁=老人、右頁=ナギ。
- 視線誘導: 左下(老人の手)→ 中央下(パン)→ 右(ナギ)→ 右奥(戸口の光)。**Z でなく、ゆるい弧**。
- 水平基調(凪)。傾けない。唯一の動きは **糸の張力差** と **戸口の斜光**。

## レイヤーと値(明度設計)

| 層 | 値 | 内容 |
|---|---|---|
| 最暗(0〜10%) | 人物シルエット・缶の山・端末筐体・床 | 輪郭で語る。内部ディテール無し |
| 中(30〜50%) | 倉庫の壁・残像(as-of) | 残像は本体より2段明るく、低彩度 |
| 明(70〜90%) | 戸口の斜光(琥珀)・糸の発光 | 画面で最も明るいのは **戸口** と **結び目** |

## 糸(主役)

- **藍の糸 `#7e93d8`**: 老人の手 → 端末。**張った直線的なテンション**。中空で **ほつれて切れる**
  ── 切断点に **明確なギャップ**、両側にフレイ(数本のほつれ)。藍の淡いグロー(ぼかし)を一段。
  *意味: 取(蓄積)への固執がほどける。*
- **薄橙の糸 `#f6c690`/`#e8a567`**: 老人 → パン → ナギへ、**やわらかな一筋**で新しく結ばれる。
  中央付近に小さな **結び目**(発光)。本体線+ぼかしグローの二重。
  *意味: 分(分け前)の縁が生まれる。*
- 同じ手の根元で **藍が解け、橙が生まれる**(片手で握りを離し、別の縁が結ばれる)。ここが画面の主題。

## 人物

- **老人(左)**: うずくまりから、**輪郭がわずかに伸びてやわらぐ**(tensegrity の弛緩)。
  力の抜けた肩。手は端末から離れかけ。顔は影、描かない。
  - **残像(as-of)**: 背後に2枚、縮こまっていた過去の姿勢を低不透明度で重ねる。**今でなく軌跡**を見せる。
- **ナギ(右)**: 立位・直立(張力が通る)。やかんに手を添える静止。**動かない**ことが芝居。

## 空間と光

- **戸口(右端)**: 細く開き、**琥珀の斜光**が床へ伸びる。光源はここだけ。
- **風(ruach)**: 戸口から数筋の細い半透明ストローク。**帆布の切れ端が一つはらむ**ことで、
  外界の風 = 心の糸の解け を **同カット内で韻**にする(P12 の風を引き継ぐ)。
- **缶の山(左奥)**: 囲い込み(取)の沈黙の象徴。最暗で小さく。

## トーン / 配色

- 全体: たそがれ藍紫 → 戸口へ向け琥珀へ。**低彩度**(joucho を色相で示し、彩度で煽らない)。
- 彩度の **最高点は結び目(薄橙)** だけ。藍は冷たく沈める。

## 文字(最小)

- セリフ無し推奨。置くなら **ナギの小さな一言**を右の余白に。フキダシは細線・小。叫び・効果音は無し。
- 見開きをまたぐ描き文字は禁止(静けさを割らない)。

## チェックリスト(納品前)

- [ ] 効果線・集中線・速度線・数値ゲージが **一本も無い**
- [ ] 画面最明部が **戸口**、彩度最高点が **結び目** になっている
- [ ] 藍に **明確な切断ギャップ** がある(繋がって見えない)
- [ ] 薄橙が **老人→パン→ナギ** を一筆で結んでいる
- [ ] 老人の **残像(as-of)** が読める
- [ ] 水平基調が保たれ、画面が傾いていない
