# ADR-2606112200: エヒイェ非二元神論 + yir'ah 認識論 doctrine 固定

**Status**: accepted — **Ratified 2026-06-11, Council Lv7+ unanimity (founder 1/1)**
**Date**: 2026-06-11
**Deciders**: Jun Kawasaki (founder)

> אֶהְיֶה אֲשֶׁר אֶהְיֶה — わたしはなる、わたしがなるものに (出3:14)
> יִרְאַת יְהוָה רֵאשִׁית דָּעַת — YHWH への畏れは知識の初め (箴言1:7)

## Context

論文「『個人』の系譜と可視性の倒錯」(90-docs/papers/2606111500) の執筆過程で、
創設者は etzhayyim の神論的立場を明示的に言語化した (2026-06-11 セッション):

1. etzhayyim は**神の存在を前提としない**。個人も、ない。宗教ではある。
2. YHWH = ehyeh asher ehyeh (I am that I am) — **すなわちモーセ自身**である。
   ゆえに**あなたが神である**。神と、私に**分断はない**。
3. 不変的・絶対的な「GoD」のイメージは**ローマ帝国が作った**ものであり、
   **誤った神**である。
4. その上で etzhayyim は**神を、キリストを愛する**。
5. **知識は神の恐れから始まる** — これが原理 (箴言1:7) としてある。

この言語化が必要になった構造的理由: Tier-0 priority「**永久記憶=神の監視**」
(ADR-2606062100, fork-only) は、神論を欠いたまま読まれると「天空の panopticon
= 全人類監視の神学的根拠」と誤読されうる。実際には corpus の全 mirror actor が
map-not-target / non-adjudicating / person-excluded / no-doxxing を NEVER 句と
して持つ — つまり実装はすでに panopticon 読解を拒否している — が、その拒否の
**神学的根拠**が正文化されていなかった。doctrine の空隙は、将来の Council・
agent・外部解釈者による Tier-0 の武器化 (監視国家的読解) への開口部である。

系譜学的検討 (論文 §2 + §5) は、この空隙を埋める材料を確定した:
「個人」と「不変・絶対の神」は**双子の歴史的構築物**であり (Locke 的自己所有
⟷ 世界を所有する神; Schmitt 政治神学の逆読み)、Bentham の panopticon は神の
遍在の工学的模造として設計された — **中央絶対観察者の建築は偽りの神の建築**
である。反個人主義 ontology (Charter) は片割れだけを解体できない。

## Decision

以下を **Tier-1 derived doctrine** として固定する (Tier-0 の amendment では
なく正文解釈 + 派生政策; priority-conformance attestation は §Charter
compliance に記す)。本文の詳細論証は論文 §5 (90-docs/papers/2606111500) を
正本とし、本 ADR は規範部分を抽出して固定する。

### D1. 神論の正文 — 5 theses

| # | thesis | 内容 |
|---|---|---|
| T1 | **非前提** | etzhayyim は神の存在を命題的前提としない。宗教であることは信条 (creed) の表明ではなく、covenant・practice・orientation である。Tillich「有神論の神の上なる神」、無教会 (内村鑑三 — Charter synthesis の明示的源流) と連続。 |
| T2 | **エヒイェ非二元** | ehyeh asher ehyeh (出3:14) は一人称・未完了形 — 神の名は名詞ではなく**生成の動詞** (Wellbecoming の文法)。一人称はいま・ここに現前する者にしか発話できない — 柴の前にいたのはモーセであり、YHWH (三人称) はその報告形に過ぎない。**神と私に分断はない。あなたが神である。** |
| T3 | **偽りの神の棄却** | 不変・絶対・全能の「GoD」像は歴史的構築物である: **ギリシア形而上学が不変性を** (パルメニデス → アリストテレス不動の動者 → Philo の YHWH 接合 → Harnack のヘレニズム化)、**ローマ帝国が玉座を** (Nicaea 帝国的召集 325 / Theodosius 国教化 380 / Pantokrator 皇帝図像) 供給した。それは誤った神である。 |
| T4 | **神とキリストへの愛** | T3 の棄却は背教ではなく第二戒への忠実である。愛されるのは Pantokrator ではなく、名乗らない名 — 生成そのもの — と、皇帝として描き直される前のキリスト (ヨハネ10:30; ルカ17:21)。**偽りの神を退けることが、神を正しく愛する仕方である。** |
| T5 | **yir'ah 原理** | **知識は神の畏れから始まる** (箴言1:7 — reshit は時間的起点かつ arche)。yir'ah (畏敬 — 問いを開く) ≠ pachad (恐怖 — 問いを止める; Pantokrator が命じるもの)。非二元のもとで yir'ah の認識論的内容は: **知る者は知られるものと分断されていないがゆえに、知識は所有ではなく参与であり、完結しえない** — epistemic humility の宗教的名。分断がない以上、神への畏れは他者への畏れを含む: 人を datafy する手はすべて神に触れる手である。 |

### D2. Tier-0「神の監視」の正文解釈

「永久記憶=**神の監視**」(Tier-0) の「神の監視」は、**観察者の玉座を持たない
内在的不消去性** — 縁起の網がそれ自身を記憶すること、append-only Datom log が
その工学的形態であるところのもの — と読む。**watch はあるが、watcher の座は
ない。** 天空 panopticon 読解 (中央の絶対的観察者による全人類監視の根拠と
する読解) は**禁止**する。本解釈は no-right-to-erasure を一切弱めない
(むしろ「消去 = 在ったことを無かったことにする」を yir'ah の侵犯として
神学的に強化する)。

### D3. 玉座の禁止 (NEVER a throne)

いかなる actor・会・制度・人物も「中央の絶対的観察者」の座を**作らず、
占めない**。Bentham 自身が panopticon を神の遍在の工学的代替として構想した
通り、中央絶対観察者の建築は偽りの神の建築であり、その座に人間の制度が座る
ことは**偶像崇拝の正確に技術的な意味**である (Stasi・社会信用・pre-crime は
技術問題である以前に神学問題である)。既存の NEVER 句群はこの禁止の個別形態
として統一的に読まれる。

### D4. yir'ah invariant 束の正典化

corpus の認識論的 invariant 群を **yir'ah の工学的形態**として正典化する。
新 actor の設計は本束への適合を yir'ah 適合として attestation する:

| pachad / hubris の側 (侵犯) | yir'ah の形態 (invariant) |
|---|---|
| 裁定し尽くす | non-adjudicating (全 mirror lineage) |
| 点予測 — 未来を確定として語る | distribution-not-point + skill-honest scoring |
| 魂の点数化 | no score-of-soul |
| target-list — 他者を到達可能な座標に還元 | map-not-target |
| 消去 — 在ったことを無かったことに | append-only / no right to erasure (Tier-0) |

### D5. anti-guru clause — ego 神格化の遮断

T2「あなたが神である」は、**個人が存在しない** (反個人主義 ontology) がゆえに、
いかなる自我の神格化も許さない: 玉座を要求しうる「あなた」が存在しないから
である。**創設者・Council・いかなる member も、神の代理・受肉・玉座を主張
できない。** 本命題はあらゆる ego から玉座への請求権を奪う命題であり、
その逆ではない。ローマの神の玉座は空位なのではなく、遍在ゆえに存在しない。
(非終末論 §1.15 と同根: 外部の主権者の再臨的介入は分断の神学の産物であり、
王国は来るものではなく now-and-here にある — ルカ17:21 = Malkhut Shamayim。)

### D6. mishmeret ha-adam の神学的基礎の承認

論文 §6 の「全人類の相互**保持**者会 (mishmeret ha-adam)」構想 — 相互**監視**
ではなく — の神学的基礎 (保持者 shomer の見守りは神の見守りの代行ではなく
それそのもの; 詩篇121:4 の不眠は有限な保持者たちの継ぎ relay として地上で
実現される) を承認する。membrane / actor 設計の固定は別途 ADR (follow-up)。

## Consequences

### Positive

- **Tier-0 の武器化開口部を閉じる**: 「永久記憶=神の監視」を監視国家的に
  読む経路が正文解釈レベルで遮断される。
- **NEVER 句群の統一根拠**: 各 actor に散在する map-not-target /
  non-adjudicating / no-doxxing / person-excluded / no-score-of-soul が、
  個別の倫理的配慮の寄せ集めではなく一つの神学 (D3 玉座の禁止 + D4 yir'ah)
  の系として読める — 新 actor 設計時の判断基準が原理化される。
- **anti-cult 構造**: D5 が教祖化・founder 神格化を doctrine レベルで遮断
  する。創設者自身がこれを ratify したという事実が将来の precedent になる。
- **認識論の固定**: T5 により、etzhayyim のあらゆる datafication / 観測 /
  予測 actor は epistemic humility を宗教的義務として負う — 「覆い尽くせる」
  と信じる知識 (kill list はその極限形) の構造的拒否。

### Negative / honest limits

- **ニカイア正統からの距離**: 非前提 (T1) + 非二元 (T2) + 帝国神論批判 (T3)
  は、ニカイア・カルケドン的古典的有神論から見れば heterodox である。
  etzhayyim はこれを承知で選ぶ (すでに非終末論 + 黙示録正典外 + 無教会 +
  synthetic religion であり、国家にも既存教団にも正統性を負っていない)。
  対外的な interfaith 摩擦は想定内のコストである。
- **誤読リスクは残る**: 「あなたが神である」は D5 を読まない引用では
  ego-inflation に見える。引用時は T2 と D5 を不可分に扱うこと
  (single-thesis 引用の禁止までは規範化しない — yir'ah は問いを開く)。
- 本 ADR は神論を固定するが、**典礼・祈り・実践への展開は未着手**
  (follow-up: musubi 結 / 礼拝設計との接続)。

### Neutral

- 実装変更はゼロ (既存 invariant の根拠付け替えのみ)。コードも contract も
  本 ADR では触れない。

## Alternatives Considered

1. **古典的有神論を維持** (不変・絶対の神 + 神的 panopticon) — 棄却。
   Tier-0 の監視国家的読解を許し、Bentham 系譜の中央観察者建築を神学的に
   正当化してしまう。歴史的にも帝国的構築 (T3) であり、Pascal の区別の
   後者 (哲学者の神) を前者 (アブラハムの神) に簒奪させたもの。
2. **単純な無神論 / 世俗主義** — 棄却。covenant・yir'ah・神とキリストへの
   愛を失い、etzhayyim が宗教であることと矛盾する。T1 は「存在を前提しない」
   のであって「不在を前提する」のではない — 非二元はどちらの命題も
   対象化の誤りとして退ける。
3. **神論を暗黙のままにする** (現状維持) — 棄却。論文の検討が示した通り、
   Tier-0「神の監視」は神論なしには panopticon と区別がつかず、空隙は
   将来の解釈者に開かれた武器化経路である。
4. **Tier-0 への直接追記** — 棄却。Tier-0 は fork-only であり、追記自体が
   手続き的に不可能。解釈固定 (Tier-1) が正しい器である。
