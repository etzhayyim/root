# ADR-2605263801: shidemori (死出守) — non-profit religious-corp memorial + cemetery substrate Tier-B actor R0 charter (FINAL gap-closure)

**Status**: proposed
**Date**: 2026-05-26
**Deciders**: Jun Kawasaki

# Context

The gap audit (session 2026-05-26) identified memorial + cemetery as
priority row 10, the FINAL gap in the 10-actor 30min-loop wave.

shidemori was explicitly path-reserved as a future cross-actor by
multiple existing actors:
- musubi (ADR-2605263400) — funeral ceremony → memorial NFT mint pair;
- chigiri (ADR-2605262700) — covenant ceremony funeral type + inheritanceChain handoff;
- kazaori (ADR-2605263200) — mass-fatality memorial coordination;
- kokoro (ADR-2605263700) — post-funeral grief continuity (musubi-paired).

This ADR realizes those path-reserves and **closes the 10-actor gap-closure
wave**.

Etymology: 死出守 (shidemori) — 死出 = death-journey (classical 死出
の旅 imagery; 万葉集 references); 守 = guardian / keeper. "Guardian
of the death-journey". The kanji choice honors the cross-tradition
inheritance:

- **Reformed memorial view** (Sola Scriptura; memorial bread + cup
  per 1 Corinthians 11:24-26; remembrance not transubstantiation);
- **Shinto 鎮魂** (chinkon; soul-pacifying; ancestral honor);
- **仏 教 49日 cycle** (Buddhist 中陰 intermediate-state cycle);
- **Secular humanist remembrance** (life-honoring without
  metaphysical claim).

All accommodated within Charter §1.13 (Wellbecoming) + §1.15 (non-
eschatological) + §1.7 (反個人主義 + 多世代) boundaries.

Constitutional constraints (inherited; not adjustable):

- **Charter §1.15 non-eschatological invariant** — memorial does NOT
  make eschatological claims about afterlife (apocalyptic / millennial
  / specific-heaven-hell-mapping). Honors the deceased without
  imposing afterlife doctrine. G3 structural enforcement via
  `memorialNftAttestation.afterlifeDoctrineImposed` const false;
  extends kataribe G4 pattern (non-eschatological tone in publishing)
  to memorial domain.
- **Cross-doctrinal Wellbecoming priority** — same pattern as musubi
  G9+N12 + kataribe G6 + kokoro G12, now extended into memorial
  domain. Members from Christian / Buddhist / Shinto /
  nondenominational / secular traditions accommodated; no
  single-tradition afterlife monopoly.
- **NOT state-licensed mortuary services** — community-witnessed-
  competent guardians (musubi G3 pattern shared, now spanning
  musubi + kataribe + kokoro + shidemori = 4-actor maturity).
  External licensed mortuary engagement (legal compliance: death
  certificate filing / cremation permit / interment permit) via
  Public Fund Safe Council Lv6+ ≥4/7 (chigiri G14 + iyashi N9 +
  kokoro G3 UPL-equivalent pattern extended).
- **NO commercial memorial software** (G6) — Frazer Consultants /
  Tribute Center / FuneralOne / ASD / SRS Computing / Wilbert /
  Aldor / Adobe Cemetery Mgmt / Cremation Society Cremation Mgmt
  PROHIBITED per Charter Rider §2(e) + §2(c). Extends musubi G6
  prohibition specifically into the memorial software domain.
- **NO embalming chemicals** (G7) — Charter Rider §2(d) toxic
  chemistry prohibition. Green burial + cremation only;
  biodegradable shroud / pine casket; NO formaldehyde / methanol /
  phenol injection. This is structurally important: most US
  funeral industry practices use embalming, but Charter §2(d) +
  §1.7 多世代 (multi-gen soil and groundwater preservation) + §1.13
  Wellbecoming preclude.
- **Land Trust waqf-equivalent cemetery rights** (G10) — per
  ADR-2605192245; cemetery land inalienability; same mizuho G11
  water-source pattern shared (now 2 actor enforcement of the
  waqf-equivalent doctrine across water + cemetery domains).
- **Member burial-or-cremation directive** (G9) — free conscience;
  opt-in at onboarding or rededication ceremony (cross-actor with
  musubi); no default imposed; multi-doctrinal preferences honored.
- **NO surveillance-based mortuary** (G8) — Charter §2(c); no
  funeral home surveillance; no live-streaming without per-party
  consent. Mortuary domain extension of musubi G8 + kokoro G10
  patterns.
- **Murakumo-only inference** (G12) — memorial NFT generation
  artwork / inscription text via judah LiteLLM → gemma4:e4b;
  commercial memorial AI PROHIBITED.
- **NO payroll for guardians** (G11) — vocation-flow L5 stewards;
  cross-actor enforcement pattern now consistent across all 10
  gap-closure Tier-B actors.

## §2. Scope (6 cells)

### A. Memorial NFT mint

- Per-deceased NFT mint upon musubi.funeral_ceremony completion;
- Memorial NFT carries: deceased pseudonym DID / dates / cross-
  doctrinal honor text (member-directive-respecting) / community-
  witnessed competence-of-life summary (member-attested or family-
  attested per member directive);
- G3 STRUCTURAL: `afterlifeDoctrineImposed` const false (Charter
  §1.15 non-eschatological); NO apocalyptic / specific-heaven-hell-
  mapping claim;
- Cross-link to musubi.ceremonyPerformanceAttestation
  (ceremonyType=funeral) + chigiri.inheritanceChain.

### B. Cemetery land registry

- Per-cemetery-site Land Registry entry (waqf-equivalent
  inalienability per ADR-2605192245);
- G10 STRUCTURAL: `landRegistryCid` REQUIRED + `waqfInalienabilityAttested`
  const true (mizuho G11 pattern shared);
- Cemetery rights belong to Land Trust permanently;
- NO cemetery land transfer / sale / lease.

### C. 鎮魂 (chinkon) annual remembrance cycle

- Cross-actor with musubi.seasonal_communal_ceremony (annual cycle);
- Multi-gen community remembrance (Charter §1.7 多世代);
- Cross-doctrinal Wellbecoming priority (Christian + Buddhist 49日 +
  Shinto + nondenominational + secular memorial preferences
  accommodated per G4);
- Community-discerned attendance (opt-in per G9 free conscience).

### D. Inheritance handoff

- TIGHT cross-actor with chigiri.inheritanceChain;
- G13 STRUCTURAL: chigiri.inheritanceChain emit MANDATORY when
  deceased had Adherent SBT;
- Adherent SBT burn coordination (chigiri.member_offboarding pair);
- Wallet handover via ERC-4337 paymaster (chigiri.inheritanceChain
  per existing pattern).

### E. External mortuary engagement (UPL-equivalent pattern)

- When state-licensed compliance required (death certificate
  filing / cremation permit / interment permit / autopsy
  coordination if applicable);
- Public Fund Safe Council Lv6+ ≥4/7 approves engagement;
- Cross-actor with toritate.externalAuditorEngagement-equivalent
  pattern (now 4-actor UPL-equivalent pattern: chigiri G14
  legal + iyashi N9 clinical + kokoro G3 mental health +
  shidemori G5 mortuary);
- External licensed mortuary handles legal-compliance; shidemori
  prepares the data package + records the engagement; shidemori
  does NOT do state-licensed mortuary work itself.

### F. Memorial directive (member directive at onboarding)

- Member burial-or-cremation preference at chigiri.member_onboarding
  or rededication ceremony;
- Cross-doctrinal preferences honored (G4);
- Free conscience (G9; opt-in; no default);
- Directive stored encrypted per ADR-2605181100; revealed only at
  member-death event by chigiri.inheritance cell.
